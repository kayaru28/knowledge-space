OpenAI が2026年10月に公表した、局所平滑化予想の証明、指数時間仮説（ETH）の反証、4次元の場の量子論の存在証明について、主張の内容、公開のしかた、検証の状況、読むときの注意を、OpenAI の公式資料から整理する。数学的な正しさは判断せず、第三者の検証は未確認として扱う。

初回公開 2026-10-27 ／ 更新日 2026-10-27

ひとことで言うと

OpenAI は2026年10月26日、自社の AI モデルが数学・計算機科学・物理の3つの未解決の問題で成果を出したと公表しました。局所平滑化予想（これにより Kakeya 予想なども全次元で解決すると説明）、指数時間仮説（ETH）の反証、4次元の場の量子論（QCD を含む）の存在証明です。

いずれも、これまでの専門家の見方からは大きな主張です。OpenAI は、AI の出力を Lean という検証ツールで形式化したと述べていますが、第三者による検証の結果は、ここでは確認できていません。この記事は、OpenAI が何を主張し、何を公開し、どう検証を進めようとしているかを、公式の資料の範囲で整理します。数学的な正しさの判断は、していません。

何が公表されたのか

OpenAI が10月26日に公表した3件（OpenAI の記事より。主張は OpenAI のもの）
分野OpenAI の主張経緯公開のしかた
数学（調和解析）局所平滑化予想（1991年に提案。波が焦点を結ぶとき、最も極端な集中は短時間しか続かない、という予想）を、あらゆる次元で証明した。これにより Kakeya 予想と Stein の制限予想も、あらゆる次元で解決する。新しい補助的な偏微分方程式にもとづく証明AI の出力は10月18日。10月19日に Lean で形式化。専門家に相談して、公開の方針を決めたAI が書いた文書と Lean の証明を GitHub に公開（論文の形の原稿もある）。専門家のグループは作らず、数学者が自由に検討する
計算機科学（計算量理論）指数時間仮説（ETH）は偽である。k-CNF の充足する割り当ての数を、部分指数時間かつ多項式の領域で数える決定的なアルゴリズムを示し、3-SAT が最悪の場合に指数時間を要するという仮説を反証した（論文の要旨）AI が反証を見つけたのは10月16日。10月17日に Lean で形式化AI の文書と Lean の証明を GitHub に公開。外部の専門家3人のグループが検証し、解説する。生のデータはすべて公開し、OpenAI は、影響を理解する会議の開催費用を出す
物理（場の量子論）4次元で、ゲージ場とフェルミオンを含む、相互作用する場の量子論の、数学的に厳密な存在証明。対象は QCD と、標準模型を含む最も単純な大統一理論。副産物として、純ヤン＝ミルズ理論の存在証明も含む（ミレニアム懸賞問題の一部）ヤン＝ミルズの自然言語の証明は9月9日、QCD は9月18日。長く複雑なため、Lean での形式化を待って公表。ヤン＝ミルズの形式化は10月16日に完了外部の専門家5人のグループが検証し、解説する。AI が作った成果物は、グループが自分たちで書き上げるまで公開しない

公開のしかた：3通りを試している

  • OpenAI は、AI の出力は「生の研究データ」のようなものと位置づけ、外部の専門家に、検討の取りまとめ役を頼んだ。専門家は、3通りの公開方法を勧めた：数学は、AI の出力を公開して、研究者が自由に検討する。計算機科学は、外部のグループが解説しつつ、出力も公開する。物理は、外部のグループが解説し、資料の公開はグループに任せる。
  • どれが最も有用かは、まだ分からないとして、意見を求めている。
  • 共同の4原則：透明性（秘密保持契約は結ばず、参加者は自由に議論・発表できる）、学術的な功績を求めない（世話役を頼んだことが、その人たちが発見したことを意味しない）、貢献への評価（理解の過程で作った文書などは、グループの成果）、独立性（参加は自発的で無報酬。結論は参加者のもので、OpenAI を代表しない）。
  • OpenAI 自身が挙げた難点：最初の世話役を選ぶこと自体が、誰が先に関われるかを左右して、情報の偏りを生む。参加の間口を広げる方法も募っている。

検証の状況

  • OpenAI の主張：AI の証明は、Lean で形式化して検証した（ETH は Lean でも検証済みと記述。数学とヤン＝ミルズも形式化を完了したと記述）。Lean は、証明が正しいかを、コンピューターで機械的に確かめるプログラミング言語。
  • 第三者による検証：この記事の作成時点で、独立した専門家による検証の結果は、確認できていない。ETH の検証は外部のグループが進める。物理は、グループが成果物の公開を見送っている。
  • コミュニティの動き：10月24日に、数学者のコミュニティが、OpenAI の数学の記事（GitHub）を直すための公開リポジトリを立ち上げた。理由として、OpenAI の記事は理解しにくく、引用が不完全なことがある、と述べている。学生から教員、愛好家までの参加を呼びかけ、査読者になりたい人も募っている。

読むときの注意

  • 出どころ：OpenAI 自身が、自社のモデルの成果を公表した内容。主張の大きさ（Kakeya 予想の全次元での解決、ETH の反証、ミレニアム懸賞問題の一部）に対して、第三者の検証は、これからの段階。
  • Lean で検証された、は、「元の数学の主張が証明された」と同じとは限らない（筆者の整理）。Lean が確かめるのは、書かれた形式的な主張が証明されたこと。その形式的な主張が、元の数学の主張を正しく写しているかは、別に確かめる必要がある。
  • 物理の成果は、AI が作った成果物が公開されていないため、外から内容を確かめられない。
  • 数式の細部や、証明の正しさは、この記事では判断していない。ETH の論文の要旨と、OpenAI の記事の記述が一致していることだけを確認した。
  • 日付は OpenAI の記載。AI が出力した日、Lean で形式化した日は、OpenAI が示した日付で、独立には確認していない。

見方（筆者の整理）

  • 今回の注目点は、成果の大きさと同じくらい、公開のしかたにある。AI が出した大きな主張を、誰がどう検証し、功績をどう扱うのか。OpenAI は、外部の専門家に取りまとめを頼む方式を試し、課題（情報の偏り）も自分で挙げている。
  • 検証の結果が出るまでは、「証明された」ではなく「OpenAI が証明したと主張し、検証が始まった」と読むのが、手堅い。
  • コミュニティが、OpenAI の資料を読みやすく直す動きを始めたことは、AI の出力を人が理解する作業が、これから大きな負担になりうることを示している。
予想（conjecture）

局所平滑化予想 / Kakeya 予想
波や針の動きに関する、調和解析の有名な予想。前者が正しければ、後者も正しい、という関係にある。
指数時間仮説（ETH）
3-SAT という問題を解くには、最悪の場合、変数の数に対して指数的に増える時間が要る、という仮説。多くの論文で、他の問題の難しさを示す根拠に使われてきた。
Lean
数学の証明をコンピューターで検証するための言語。形式化とは、証明を Lean で書き直すこと。
ヤン＝ミルズ理論 / QCD
素粒子の力を記述する場の量子論。QCD は、クォークとグルーオンの強い力の理論。
ミレニアム懸賞問題
クレイ数学研究所が懸賞をかけた、7つの未解決問題。ヤン＝ミルズ理論に関する問題は、その一つ。
