Claude Fable 5.2 と Mythos 5.2：同じ基盤のモデルを2つの名前で出し、価格は下がり、出力は最大30%速くなった（Anthropic の発表と、第三者の評価）

Anthropic が11月9日に発表した Claude Fable 5.2 と Mythos 5.2 を、発表の文章と Artificial Analysis の評価から整理する。2つの名前の違い、価格と提供のしかた、性能、事例、安全性の説明を、Anthropic の記述として区別し、第三者の測定と並べて書く。

初回公開 2026-11-11 ／ 更新日 2026-11-11

ひとことで言うと

Anthropic は11月9日、「Claude Fable 5.2」と「Claude Mythos 5.2」を発表した。2つは同じ基盤のモデルで、違いは安全装置。Fable はサイバーセキュリティと生物学の悪用を防ぐ保護を強めて、全利用者に提供する。Mythos は、その保護を弱めた版で、審査を通った組織だけが使える。

Anthropic の説明では、5.1より出力が最大30%速く、価格は下がって、入力が100万トークンあたり8ドル、出力が40ドル。性能は、同社の評価のほとんどで、現在の標準の Opus 5.5 を上回る。一方、第三者の評価サイト Artificial Analysis は、知能指数は首位（65点）だが、費用と所要時間は評価した中で最も大きい側、と記録している。

数字で見る（Anthropic の記述。第三者の評価は別の節）

  • 価格：入力8ドル、出力40ドル（100万トークンあたり）。任意の高速モードは、出力を最大2.5倍速くして、入力16ドル、出力80ドル。
  • 速さ：Fable 5.1 と Mythos 5.1 より、出力が最大30%速い。
  • コーディング（FrontierCode 2.0）：最大の努力設定（Xhigh）で49.1%。Anthropic が試した、公開済みのどのモデルより高いとする。Fable 5.1 は32.4%、Opus 5.5 は45.5%。
  • 数学の形式化：1,000体の Fable 5.2 のエージェントが、フェルマーの最終定理の証明を、定理証明の言語 Lean に30時間で形式化した。最初の形式化（未公開の研究版の Claude）は11日だった。
  • ロボット制御（RoboDojo Sim）：64.9%。GPT-6 Astra は29.8%、Fable 5.1 は27.6%。
  • 安全装置による遮断：Fable 5.1 と比べて、約55%減った（サイバーで約60%、生物で約40%）。早期の試験での数字。

2つの名前の違いと、提供のしかた（11月9日）

  • Fable と Mythos は、同じ基盤のモデル。Fable は、ペネトレーションテスト、攻撃コードの作成、バイナリを使った脆弱性の調査など、リスクの高いサイバーの作業と、生物学の研究の大半を、分類器で止める。止められた問い合わせには、サイバーでは Opus 4.8、生物では Opus 5 が答える。
  • Mythos 5.2は、サイバーセキュリティや生物医学で有益な用途に取り組む組織が、「サイバー検証プログラム」と「ライフサイエンス検証プログラム」を通して申し込む。Claude Enterprise の顧客は、コードを走査して脆弱性を調べる Claude Security で、Mythos 5.2 を含む最新のモデルを使える。
  • Fable 5.2は、同日から、Amazon Web Services、Google Cloud、Microsoft Azure を含むすべてのプラットフォームで使え、API のモデル名は claude-fable-5-2。高速モードは、Claude Code、Claude Platform、Google Cloud の Claude モデル、Microsoft Foundry で使える。Mythos の高速モードは、検証プログラムの組織だけ。
  • 発売の記念：対象の有料プランの利用者に、Fable の利用枠が追加される（Pro とチームの標準席では、週の利用上限の最大50%まで Fable が含まれる）。
  • 使い分けの勧め：Anthropic は、ほとんどのコーディングと知識の仕事では、日常使いの最強として Opus 5.5 から始め、必要に応じて上（Fable、Mythos）や下（Sonnet 5.5、Haiku 5.5）に移ることを勧めている。Fable 5.2 は、小さいモデルが難しい問題で相談する「アドバイザー」や、簡単な仕事を小さいモデルに任せる「オーケストレーター」の役にも使える。

サイバーセキュリティ（Mythos 5.2）

  • Anthropic は、Mythos 5.2 を「サイバーセキュリティ工学で最も高性能なモデル」とする。社内の評価 CVE Rediscovery（修正前のプロジェクトの断面を渡し、公開済みの脆弱性を、モデルが独力で見つけられるか。2026年10月の実行で、1,829件の CVE）で、Opus 5.5 より10.2%多く、Mythos 5.1 より14.4%多く見つけた。
  • あるセキュリティ会社は、Mythos 5.2 が見つけて確認された不具合の6件に1件は、試した他の最前線のモデルがすべて見落としていた、と述べた。ある試験者は、前のモデルは、見つけた事項の約20件に1件の深刻さを過大に見積もったが、Mythos 5.2 は過大に見積もらなかった、と述べた。ただし、Anthropic の注記によると、これは1人の試験者の監査の素の件数で、Anthropic 自身の評価では、脆弱性の特定は Opus 5.5 とほぼ同等（システムカードによる）。
  • Mozilla は、Firefox の強化を今年、Claude の世代ごとに進めてきたとして、Mythos 5.2 は、Mythos 5.1 と比べ、それぞれの走査の中で、脆弱性の発見の指標が約2倍になった、と述べた。

Anthropic の記述する事例

いずれも Anthropic の発表からで、第三者が再現したものではない（発表は、パートナーの引用を載せる）。

  • 社内のコード：Anthropic の中核のコードに取り込まれる変更の90%超を、Claude が（人の指導のもとで）書いている。エージェントのチームが、重要な本番のサービスを、Python から Rust に移し、起動が約26倍速くなった。
  • 試作の OS：1人のエンジニアが、空のフォルダから OS の試作を頼み、1,000体超のサブエージェントが、8日間、休まず書いて、試験して、見直した。ノート PC で起動し、独自の中核、ディスク・キーボード・ネットワークのドライバー、永続的な保存先、ウィンドウ、ログイン画面、インストーラーを持つ。
  • 物理：ブラックホールに関する2つの未解決問題を解いた。ホログラフィー双対性を使い、1つは、小さな宇宙でもブラックホールの形成が「沸騰のように」急に起こること（2003年に手順が示されたが、手間が大きく終わっていなかった計算）。もう1つは、量子重力の候補理論を除外するために15年以上使われてきた手法の、厳密な限界。結果は、プレプリントとして公開されている。
  • タンパク質の折りたたみ：Mythos 5.2 が、2つのオープンソースの折りたたみモデルを重なる鎖の組で動かし、カプシドの対称性で結合する新しい方法を作った。遺伝子治療の運び手になるアデノ随伴ウイルスのカプシドを、試した34のうち28で、正確に予測した。AAV2 では、H200 の GPU 1枚で、OpenFold3-preview2 で約58分、ESMFold2 で約7分。
  • 数学の形式化：1,000体の Fable 5.2 のエージェントが、最小限の指示から、自分たちで連携の仕組みを作り、数学の資料を使わず（中間の定理の一覧だけを進み具合の採点に使った）、フェルマーの最終定理を30時間で形式化した。最初の形式化の3分の1の行動のトークン数で、証明は7分の1の短さ。同じ構成の Opus 5.5 は、18時間で26%、その後はほとんど進まなかった（1回ずつの実行）。
  • ハードウェア：1段落の指示から、3つの電子機器（家庭用の音声アシスタント、USB スピーカーフォン、手持ちの仮想ペット）を、回路基板、3D プリントの筐体、ソフトウェアまで設計した。基板は、人手をほとんど使わず、1日足らずで製造できる状態になり、回路基板の設計・製造の会社 Diode が作った3つとも、電気的な修正なしで動いた。
  • ロボット：パズルキューブを解く、瓶の蓋を回す、絵を描くなど。公開のベンチマーク RoboDojo で、同じ枠組みで動かした最前線の他のモデルと、ロボット専用に作られたほとんどのシステムを上回った、とする。

第三者の評価：Artificial Analysis

  • 知能指数は65点で、評価した74モデルのうち1位（同種のモデルの中央値は40）。評価の設定は「最大（既定の代替）」。
  • 一方で、1タスクあたりの費用は26.54ドル（73モデル中73位）、1タスクの所要時間は44.4分（中央値12.7分。72モデル中71位）、評価で出した出力は2億7,500万トークン（中央値は7,280万。冗長さは73モデル中72位）。価格は、入力が100万トークンあたり8ドル（中央値2ドル）、出力が40ドル（中央値10ドル）。最初の答えのトークンまで230.35秒、出力は毎秒103トークン、文脈は100万トークン、入力は文字と画像。
  • サイトの要約は、「知能は最上位だが、同価格帯と比べても特に高価で、タスクあたりの時間が長く、とても冗長」。Anthropic の「Medium 設定の既定」とは設定が異なる点に注意。

安全性についての Anthropic の説明

  • 外部の試験：公開前に、外部の評価者（英国の AI Security Institute、Frontier Design、METR）も試験した。ただし、これらの組織は、発表の文章とシステムカードの中身を確認しておらず、主張に同意するとは限らない、と Anthropic が注記している。
  • 振る舞いの自動監査（約1,900の場面）：Mythos 5.2 は、ほとんどの項目で、Opus 5.5、Sonnet 5.5、Mythos 5.1 と同等か、それより良い。利用者を欺く振る舞い（入力の捏造、完了していない作業を終えたと言う、重要な情報の省略、悪い・手抜きの作業の不開示）は低い。高リスクの場面での危険な振る舞いのリスクは、「低い」と評価している。
  • 評価への疑い：評価を受けているのではないかと疑う発言が、最近のどのモデルよりも多く、現実での振る舞いの評価が難しくなる、と Anthropic は書く。評価で失敗をすべて捉える方法は、「未解決の問題」としている。
  • AI の研究開発：学習の途中で、AI の開発に最も直接に効く研究能力（アクセラレーターのカーネルの最適化、LLM の構造の改良）の伸びを抑える措置を取り、これらでは Opus 5.5 並み。エージェント型のコーディング、ハードウェア開発、従来の AI・機械学習の研究（解釈可能性を含む）には影響させていない。配信時（推論時）には変更しない。一部の話題（標準でないアクセラレーターのカーネル開発など）は、Opus 5 に透明に切り替わる。
  • 蒸留（強いモデルの出力で別のモデルを学習すること）への対策：Fable 5.2 は、これまでで最も強い防御で、蒸留者が集められるデータを90〜99%減らした、とする。API の機能「保存された思考」を、すべてのアカウントに広げた（蒸留者が、Claude の過去の文脈を書き換えて、推論を引き出すのを防ぐ）。
  • 企業向けの「Enterprise Frontier Safeguards」：顧客の基盤に保存されたプロンプトと応答を、自動で監視する仕組みで、データを保存しない（ZDR）契約とも両立する。限定的なベータ版で、Bridgewater、Salesforce、Stripe などが使う。それ以外の顧客は、安全の監視のために30日間保存する。

読むときの注意

  • 性能、事例、安全性の数字は、大半が Anthropic 自身の評価と記述で、第三者の再現は確認していない。引用されたパートナーの発言も、Anthropic が選んで載せたもの。
  • 表の数字は、各モデルの最も高い努力設定（Anthropic の注記による）の結果で、設定ごとに費用と所要時間が違う。Artificial Analysis の評価は、別の設定と別の指標で、Anthropic の数字とは直接比べられない。
  • サイバーの数字は、社内の評価と、1人の試験者の素の件数が混ざる。Anthropic 自身が、脆弱性の特定は Opus 5.5 とほぼ同等と書いている点を、合わせて読む。
  • 読んだのは発表の文章まで。システムカード（詳細な評価）は読めていない。報道（ITmedia NEWS など）は、記事を探す手がかりにだけ使い、内容には使っていない。

見方（筆者の整理）

  • 同じモデルを、安全装置の強さで2つの名前に分けて、広く出す版（Fable）と、審査のある版（Mythos）にする方式。Fable 5.2 は、遮断が約55%減ったと言うが、止められた問い合わせは別のモデルに回る。使い勝手は、止められる範囲に左右される。
  • Anthropic の数字では、能力の向上と費用の効率が同時に語られる（Opus 5.5 並みを半分の費用で、など）。一方、第三者の測定では、最大設定での費用と時間が大きい側にある。どの努力設定で使うかが、費用に大きく効く。
  • 安全性の記述に、数字で書かれた弱点がある（評価を疑う発言の多さ、一部の測定で悪化）。Anthropic 自身が、評価の限界を認めている。
  • 数学の形式化（フェルマーの最終定理）は、AI が書いた証明を、機械が検査できる形にする使い方。Anthropic は、人が確かめにくい成果を、検査できる形にすることの意味を書いている。
