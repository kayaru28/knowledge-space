Anthropic の株式公開の目論見書（S-1）を読む：半年で163億ドルの売上、巨額の赤字の中身、創業者と信託が握る議決権、そして空欄のままの項目

2026年10月26日に米国証券取引委員会へ提出された Anthropic の S-1 から、売上と費用、赤字の内訳、顧客数の推移、公益法人と長期利益信託による議決権の仕組み、リスク要因での AI の危険性の書き方、IPO価格や契約総額など空欄のままの項目を、原本をもとに整理する。

初回公開 2026-10-29 ／ 更新日 2026-10-29

ひとことで言うと

Anthropic は2026年10月26日、株式公開（IPO）の登録届出書「S-1」を、米国証券取引委員会（SEC）に提出しました。Nasdaq に「ANT」の記号で上場する計画で、書類の本体が公開されたことで、売上や費用、株式の仕組みが原本で読めるようになりました。

数字で目立つのは、2026年上半期の売上が163億ドル（前年同期は11.6億ドル）と、急に伸びたことです。一方で、最終損益は上半期で807億ドルの赤字です。ただし、そのほとんどは事業の損失ではなく、転換社債などの評価額の増加という会計上の項目です。なお、IPOの価格、株数、計算資源の契約の総額などは、この版では空欄のままです。

提出の経緯

  • 2026年6月1日：Anthropic が、登録届出書の草案を非公開で SEC に提出したと発表した。IPO は、市場の状況などに左右され、株数と価格はまだ決まっていない、と述べている。
  • 2026年10月26日：公開の版（S-1）が提出された。表紙には「この目論見書は未完成で、変更されることがある」と書かれ、株数と価格帯は空欄になっている。
  • 上場の計画：Class A 普通株を、Nasdaq Global Select Market に「ANT」の記号で上場する。会社が新たに売る株と、既存の株主が売る株の両方がある。株主が売る分の代金は、会社には入らない。

最終損失807億ドルの中身

  • 最終損失の大半は、「転換社債・デリバティブ負債・SAFE（将来株式の合意）の公正価値の変動」で、2026年上半期は724億ドル。注記は、企業価値が上がったため、これらの評価額が増えたことが主な理由だと説明している。
  • つまり、評価額の増加が、費用として計上された形。現金が出ていくものではない。営業損失（6.9億ドル）とは、性質が違う。
  • 貸借対照表（2026年6月30日）：現金と短期の投資は合わせて1,317億ドル。これまでに調達した資金は累計1,411億ドル。優先株式は1,575億ドルで、株主資本の外に置かれているため、株主資本は1,276億ドルのマイナスになっている。上場時に優先株式は普通株に転換される予定。

議決権の仕組み

S-1 が示した普通株の種類（上場の完了後）
種類持つ主体議決権
Class A一般の株主（今回の上場の対象）1株につき1票
Class N公益のための基金などなし（法律で必要な場合のみ1票）
Class T長期利益信託（LTBT）取締役の過半数を選ぶ・解任する権限
Class F共同創業者7人の有限責任会社（1株）議決権全体の50.1%
  • 公益法人：Anthropic はデラウェア州の公益法人（PBC）。取締役は、株主の利益、事業の影響を受ける人々の利益、「高度な AI を責任をもって開発し維持して、人類の長期の利益に資する」という目的を、両立させる義務を負う。
  • 長期利益信託：利害のない5人の受託者が、AI の安全、国家安全保障、公共政策、社会的事業の専門性をもつ。日々の経営や戦略は決めないが、取締役の過半数を選び、解任できる。
  • 創業者：上場の直前に Class F の1株を、共同創業者7人の有限責任会社に発行する。この1株が、議決権全体の50.1%を持つ。信託と創業者の有限責任会社は、株主間契約で、取締役の構成と指名について合意する。
  • 支配会社の扱い：信託が取締役の過半数を選べるため、Nasdaq の規則上の「支配会社」にあたる。ただし、指名とガバナンスの委員会を除いて、この例外は使わない見込みと書いている。
  • 公益の基金：2026年6月30日の完全希薄化後の株式の5%（8億4,684万960株）の Class N を、100%子会社の基金に渡した。さらに、株価が前のマイルストーンから50%上がるたびに、最大2%の追加を、取締役会の裁量で渡せる枠組みを承認した。共同創業者は、個人の持ち株の80%を慈善に使うと誓約している。

リスク要因での AI の危険性の書き方

  • 書類には、「十分に高度な AI は、適切な安全策や監督がなければ、人類にとって壊滅的または存亡にかかわるリスクをもたらしうる、という懸念が、社内からも、ほかの研究者、規制当局、政策担当者、業界の関係者からも示されている」という趣旨の記述がある。
  • 続けて、「自社のモデルが、自社の研究のペースを上げていることを観察している。AI の研究開発が大きく自動化されるほど、これらのリスクは高まる」と書いている。
  • 別のリスク要因として、報道や世間の議論で「AI が仕事を奪う」「悪用される」「存亡のリスクがある」という見方が繰り返されていて、同社がその焦点のひとつだと述べる。「その懸念が正しいか、自社のモデルに当てはまるかにかかわらず」評判に影響しうる、という書き方をしている。
  • エージェント型の AI については、ユーザーに代わって、外部のシステムとやり取りし、コードを実行し、取引を完了するなど、限られた人の監督で自律的に動くことで、害を及ぼすリスクが増えうると説明している。
  • 米国の複数の州の司法長官が、業界の別の会社の AI の安全性について調査を発表したことにも触れている。

まだ空欄の項目

  • IPO の価格帯、売り出す株数（会社分と株主分）、上場後の資本の見込み
  • 計算資源などの購入契約と、リースの総額。大半が2031年から2045年に発生する見込みと書いているが、金額は空欄
  • 2026年10月31日時点の年換算の売上（Run-Rate Revenue）
  • 直近12か月の顧客別の売上の割合、一部の追加の数字

読むときの注意

  • 未完成の書類：「予備目論見書」で、SEC の審査の途中。株数や価格など、空欄が埋まる前に内容が変わる可能性がある。この記事は、2026年10月29日時点で読める版にもとづく。
  • 最終損益は読み方に注意：807億ドルの赤字は、評価額の増加による会計上の項目が大半。営業損失は6.9億ドルで、これは別の数字。
  • 「調整後」は自社の定義：調整後の営業利益は、会社が定義した非GAAP指標。株式報酬（上半期で22億ドル）などを除くため、通常の会計基準の営業損失（6.9億ドル）とは違う。
  • 「9割」の範囲：Claude が書いたのは「自社のコードへの貢献」の割合で、2026年9月のもの。業界全体の話でも、人間の確認がないという意味でもない。
  • 危険性の書き方：リスク要因は、投資家への開示として書く部分。「懸念が示されている」という書き方で、会社自身が断定しているわけではない。
  • 本稿は筆者の整理であり、投資の助言ではない。

用語メモ

S-1
米国で株式を新規に公開するときに、SEC に提出する登録届出書。会社の事業、財務、リスク、株式の仕組みなどを載せる。
公益法人（PBC）
株主の利益だけでなく、定款で定めた公益の目的も考えて経営することを、法律で求められる会社の形。
長期利益信託（LTBT）
株主としての利害をもたない受託者が、取締役の過半数を選ぶ権限をもつ仕組み。
転換社債・SAFE
将来、株式に換えられる資金調達の方法。会社の評価が上がると、それらの評価額も増え、会計上の費用になる。
純収益維持率
同じ顧客の売上が、基準の時点と比べて、どれだけ増減したかを表す割合。900%は約9倍。
調整後の営業利益
会社が定義した、通常の会計基準にない指標。営業損失から、株式報酬、現金を伴わない寄付、和解金を除いて計算する。
支配会社
取締役を選ぶ議決権の過半数を、特定の主体が握る会社。Nasdaq の統治の規則の一部を免れる。
