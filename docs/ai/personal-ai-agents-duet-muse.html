利用者に代わって動く AI エージェントのアプリが相次ぐ：Claude Duet と Meta の Muse、そして GPT-6.1 Terra

2026年10月に出た、Anthropic の Claude Duet、Meta の Muse、OpenAI の GPT-6.1 Terra について、各社の公式資料から、できること、人が承認する場面、認証情報と情報の扱い、提供の範囲を整理し、読むときの注意をまとめる。

初回公開 2026-10-27 ／ 更新日 2026-10-27

ひとことで言うと

2026年10月、利用者に代わって自分で作業を進める AI エージェントのアプリが続けて出ました。Anthropic の「Claude Duet」（10月21日、米国で研究プレビュー）と、Meta の「Muse」（9月に北米で開始、10月23日に日本で提供開始）です。OpenAI は10月26日に、画面操作が得意で安い「GPT-6.1 Terra」を出しました。

どれも、メールの送信や買い物のような重要な操作の前に、本人の承認を求めると説明し、パスワードや支払い情報をモデルに見せない設計を挙げています。この記事は、各社の公式資料から、何ができて、どこで人が判断するのかを並べます。評価はすべて各社自身のもので、独立した検証は確認していません。

Claude Duet：先回りして知らせる

  • Anthropic は、Claude Duet を「先回りするエージェント」と呼ぶ。Claude のアプリは、利用者が開いてから一緒に作業するのに対し、Duet は、利用者のところに来て、何が注意を要するかを知らせる。
  • 対象は、手が回らない専門職や、小さな事業の経営者。Claude Opus 5.5 を土台に、何が自分の判断を要し、何が後でよく、いつ先に確認するかを決めることを重視している。
  • 承認の頻度の設計：承認が多すぎると、利用者が内容を見ずに押す「承認疲れ」が起きる、と同社自身が課題に挙げている。頻度は調整を続ける。
  • 検証：社内の評価、赤チーム（攻撃側の試験）、外部会社による侵入試験（ソースコードにもとづく。クラウドのブラウザとサインイン画面を対象にした追加の試験が進行中）を行い、同社の公開のバグ報奨金の対象にも入れた。
  • ブラウザの識別：Duet のブラウザは、固有の User-Agent を付けて、公開の IP アドレスを公表し、サイト側が識別して扱えるようにしている。公開前に、大きなサイトにも連絡して、訪問を拒否できるようにし、拒否したサイトもあった。

Muse：Meta の説明

  • Meta は、Muse を「誰もが簡単に使えるように設計された、世界初のパーソナル AI エージェント」と説明している。日本の発表は、安全性とプライバシーを重視している点を強調した。
  • Meta の決算発表（10月21日）で、最高経営責任者は「Muse と、最初の最先端モデルである Muse Wonder を出した」と述べている。利用者数などの数字は、決算のリリース本文には載っていない。
  • 今回読んだのは、日本での提供開始の発表と決算のリリース。安全性の詳細は、9月の発表記事に載っているとして、日本の発表は参照しているが、この記事ではその記事を読んでいない。

エージェントを動かす側のモデル：GPT-6.1 Terra

  • OpenAI は10月26日に、速くて効率のよいモデル「GPT-6.1 Terra」を出した。画面を読む力と、精密な画面操作（コンピューター利用）、自然な文章を組み合わせ、提案書の作成、技術図面の解釈、フォームの入力、動画の編集のような仕事を想定している。
  • 価格：API の標準価格は、100万トークンあたり、入力1ドル、キャッシュされた入力0.05ドル、出力5ドル。GPT-5.6 Terra や GPT-6.1 Sol より50%安い、と説明している。
  • OpenAI の評価（自社の報告）：専門的な課題の集まり Agents' Last Exam で、中程度の推論の強さで、GPT-5.6 Terra より15ポイント高く、費用は約3分の1。トークン単価が10分の1で、GPT-6 Astra と同等。最大の推論の強さでは、Claude Opus 5.5 より、トークン効率が3倍超で、トークン単価が4分の1、1課題あたりの費用が約9分の1、と比較している。
  • 事実の誤り（社内の評価）：誤りを引き出す問題での誤り率は、低い推論の強さで53.6%から16.7%に、最大の強さでは4.3%に下がった。Terminal-Bench 4.0 は50.3%で、GPT-5.6 Terra の公表値21.5%の2倍超。複雑なコーディングには、GPT-6.1 Sol と GPT-6 Astra のほうがよい、と案内している。
  • 安全：OpenAI の備えの枠組みで、サイバーセキュリティが「Critical」の水準に達している、と明記している。プロンプトインジェクションへの耐性も、社内の試験で強かったと述べている。
  • 提供：ChatGPT Work と Codex で、Plus、Pro、Enterprise、Edu 向けに今日から。API では gpt-6.1-terra。

読むときの注意

  • 各社の自己申告：安全性の設計も、性能の比較も、各社自身の公表。承認や分類器が、実際にどの程度、誤りや悪用を防げるかは、独立した評価が必要で、ここでは確認していない。
  • 提供の範囲が違う：Duet は米国の Pro・Max の順番待ち、Muse は日本を含む提供、Terra は ChatGPT とAPI。同じ条件では比べられない。
  • 表の比較の限界：各社が書いた項目を並べたもの。書かれていないことは「ない」ではなく「この資料では分からない」。例えば、Duet の広告への利用、Muse の承認の頻度の設計は、読んだ資料に書かれていない。
  • Muse の安全性の詳細（9月の発表）は、この記事では未確認。Meta の日本向けの発表に書かれた範囲だけを載せている。
  • 筆者の道具との関係：この記事をまとめた筆者の道具には、Claude Duet の提供元と同じ会社（Anthropic）の AI が含まれる。Duet の記述は、同社の公開資料にもとづく。

見方（筆者の整理）

  • 3つとも、「何を任せ、どこで人が止めるか」の設計が中心にある。Duet と Muse は、重要な操作の前に承認を求め、認証情報をモデルから隔てる。違いは、細部（どの操作を承認の対象にするか、別の確認を誰が行うか、情報の共有の規則）にある。
  • 承認の頻度は、安全と使いやすさの綱引きになる。Duet の資料は、承認疲れを認めている。承認を細かくするほど安全になるわけではない。
  • エージェントが認証情報を持たない設計は、フィッシングへの強さを生む一方で、サインイン画面そのものが、なりすましの標的になる。Duet の資料は、サインインの入力欄は、アプリ内にだけ現れ、リンクやメールでは来ない、と利用者向けの注意を書いている。
