OpenAI のモデルが、Google Cloud でも使えるように：競合のクラウドの Model Garden で、GPT-6 Astra など3モデルの限定プレビューが始まった

2026年10月21〜22日に OpenAI と Google Cloud が発表した、OpenAI の最新モデルと Codex を Google Cloud の Model Garden で提供する取り組みについて、3つのモデル、購入とデータの扱い、これからの予定、発表に書かれていないことを、両社の公式の発表から整理する。

初回公開 2026-10-27 ／ 更新日 2026-10-27

ひとことで言うと

2026年10月21日、OpenAI は、自社の最新モデルと、コーディングの道具「Codex」を、Google Cloud の「Model Garden」（AIモデルを選んで使うための場）で提供すると発表しました。Google Cloud も、10月22日付のブログで、GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna の3モデルの提供を始めたと説明しています。

いまは、一部の企業の顧客に向けた限定プレビュー（private preview）です。OpenAI は、一般提供を「数週間のうちに」としています。購入は Google Cloud Marketplace を通じて行い、Google Cloud の契約の枠から支払えます。一方で、OpenAI は、Microsoft が引き続き主要なクラウドのパートナーだと書いています。

発表の中身

OpenAI の発表（10月21日）

OpenAI の最新モデルと、Codex のエージェント的な作業の流れを、Google Cloud の Model Garden に組み込む。利用者は、Google Cloud のデータ管理と高性能な基盤のもとで、これらのモデルを使える。OpenAI のモデルは、まもなく Google Antigravity と Gemini Agent でも使えるようになる、としている。

Google Cloud の発表（10月22日付）

Model Garden で OpenAI のモデルの提供を始めた。限定プレビューとして、一部の企業の顧客に順次提供していて、ほかにも「まもなく」追加する。いまから、API を通して使えるほか、手元の Codex の CLI やデスクトップの作業を、Google Cloud の Gemini プラットフォームにつないで推論させることもできる。

3つのモデル（Google Cloud の説明）

GPT-6 Astra：コーディング、コンピューターの操作、専門的な仕事、科学研究のような難しい作業向け。GPT-6.1 Sol：Astra に近い知能を、より低いコストで、エージェントによるコーディングやコンピューターの操作、専門的な仕事に。GPT-6 Luna：日常の仕事を大量にこなす、速くて費用を抑えたモデル。

買い方（両社の説明）

OpenAI のモデルは、Google Cloud Marketplace を通じて購入する。Google Cloud との契約で、利用額の約束（コミット）がある企業は、その枠から支払える。Google Cloud は、利用がすべて1つの請求書に載り、モデルの提供元をまたいだ「柔軟な節約プラン」の対象にもなると説明している。

データの扱い（Google Cloud の説明）

  • 顧客の入力、文脈、出力は、指定したデータの境界の中にとどまり、基盤となるモデルの学習には使われない。データを残さない設定（Zero Data Retention）は「まもなく」提供される。
  • OpenAI のモデルは、専用の Google Cloud の基盤で動く。機密情報を保護したまま計算する Confidential Compute は「まもなく」。通信は、強化された隔離したゲートウェイを通り、外部のモデル提供元が、顧客のクラウド環境に不正に入れないようにする。
  • モデルとのやり取りは、認証された ID のもとで行われ、管理者は、VPC Service Controls と、統一された監査ログで、全体を見られる。

見方（筆者の整理）

  • 選ぶ場所が増えた：企業は、すでに契約しているクラウドの枠の中で、OpenAI のモデルを選べるようになる（一般提供になれば）。モデルの提供元ごとに契約を分けなくてよい、と Google Cloud は説明している。
  • OpenAI は、提供の窓口を広げている：OpenAI の発表ページの関連記事には、6月10日付の「Oracle のクラウドの契約の枠で、OpenAI のモデルと Codex を使う」という題の記事も並んでいる（中身は読んでいない）。Microsoft を主要なパートナーとしたまま、複数のクラウドで提供する流れに見える。
  • Google Cloud は、「主要なクローズドソースの LLM を3つとも提供する、唯一のハイパースケールのクラウド」だと主張している。これは同社の説明で、ほかの会社の提供状況は確認していない。
Model Garden
Google Cloud で、いろいろな AI モデルを選んで使うための仕組み。
Codex
OpenAI のコーディングの道具。ソフトウェアの開発作業を、エージェントとして進める。
限定プレビュー
一部の顧客だけに、試験的に提供すること。
Google Cloud Marketplace
Google Cloud の契約のもとで、ほかの会社のソフトウェアやサービスを購入できる場。
コミット（利用額の約束）
クラウドを一定額まで使うと約束する契約。その枠の中から、購入の支払いができる。
Zero Data Retention
顧客の入力や出力を、提供側に残さない設定。
Confidential Compute
データを暗号化したまま、安全な領域で計算する技術。
