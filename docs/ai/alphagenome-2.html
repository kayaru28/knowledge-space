AlphaGenome 2：DNA の変異が「どの細胞で」効くかを予測する、Google DeepMind の次世代モデル

Google DeepMind が2026年11月11日に発表した AlphaGenome 2 の、設計の変更点（細胞の種類を条件にする）、公式が示す性能（TenK10K など）、使える範囲と注意を、DeepMind のブログをもとに整理する。数値は DeepMind 自身の報告。

初回公開 2026-11-20 ／ 更新日 2026-11-20

ひとことで言うと

Google DeepMind は2026年11月11日、DNA の配列と、その変異が、特定の細胞の種類ごとにどう働くかを予測する次世代のモデル「AlphaGenome 2」を発表しました。前のモデルは、組織全体の平均的な活動を予測していましたが、今回は、心筋の細胞や免疫の細胞のような、細胞の種類と状態を単位にしています。

DeepMind は、遺伝子の発現を変える変異を、前の最先端のモデルのほぼ2倍見つけられると書いています。1億を超える個々の細胞のデータ（68の組織にわたる）で学習し、非商用の研究には API で、商用の研究には Google Cloud の限定プレビューで提供しています。これは DeepMind 自身の報告です。

何が変わったか

条件つきのモデル

前のモデルは、100万文字の DNA から、多数の組織・細胞株の実験の結果を、並列に予測していた。今回は、「組織・細胞の種類・状態」のどれかを1つ条件として DNA と一緒に入力し、その条件での効果を予測する。能力が分散して、近い細胞の違いを捉えにくい問題を、設計の変更で改めた、と説明している

細胞の状態を持ち込める

参照用の細胞の種類の一覧から選ぶか、研究者自身の単一細胞の実験から、細胞の状態を表す入力を、その場で作れる。数十個の細胞の遺伝子の活動のデータでも、再学習なしで、新しい細胞の状態に適用できる、と書く

欠けたデータの補完

細胞の状態と出力を分けるため、遺伝子の活動だけを入力しても、染色質へのアクセスのしやすさなど、測っていない性質を予測できる。次にどの実験をするかの優先づけに使える、と書く

DNA メチル化を追加

遺伝子の発現、ヒストンの修飾、染色質へのアクセスのしやすさに加えて、要望の多かった DNA メチル化も予測する

DeepMind が示す性能

  • 細胞の種類ごとの違い：学習に使っていない領域で、同じ組織の中の細胞の種類による遺伝子発現の違いを、前のモデルより多く説明する。血液の幹細胞が赤血球や免疫の細胞に成熟する連続的な変化もたどれる、と書く。
  • TenK10K（免疫の細胞28種の大規模な単一細胞の地図）：因果の変異を30%、遺伝子への効果の向きを43%見つけた。単一細胞のデータで調整した前のモデルと他の専用の手法は、それぞれ16%と23%。
  • 炎症性腸疾患（IBD）の例：遠くの調節領域にある変異が、腸の免疫細胞（マクロファージ）で ETS2 遺伝子を過剰に働かせて IBD につながる、という最近の研究の結果を、計算で再現した。原因の変異を選び出し、ほかの細胞や遺伝子への影響は小さいことを示した、と書く。
  • 新型コロナのワクチンの例：ワクチンの研究の、見たことのない単一細胞のデータで、活性化した T 細胞と静止した T 細胞を区別した。重症の新型コロナに関係する変異が、活性化した状態で、遺伝子の活動をより強く乱すことも示した、と書く。

遺伝学と単一細胞の橋渡し

  • 病気や形質に関係する変異について、数百の細胞・組織の条件での予測を、あらかじめ計算して提供している（研究者が大規模な計算をしなくて済むようにするため）。
  • エンハンサーと遺伝子の結びつき：実験のスクリーニングは主に培養した細胞株で行われるため、体内の特定の細胞では分かっていないことが多い。AlphaGenome 2 は、脳のアストロサイトのような、ヒトの一次細胞の種類にも対象を広げる、と書く。
  • GWAS（全ゲノム関連解析）：身長から2型糖尿病まで複数の形質で、原因とみられる変異と、働く細胞の絞り込みを助ける。確信があるときは、遺伝子の活動が上がるか下がるかの向きも、正確に当てる、と書く。

使える範囲と注意

  • 提供：AlphaGenome の API で、非商用の研究に、本日（11月11日）から提供。商用の研究は、Google Cloud の限定プレビュー。発現の条件づけの対話型チュートリアル（Colab）も公開。
  • 今後：Google Antigravity（エージェント型の開発基盤）向けの「AlphaGenome 2 Skills」を、近く公開すると書く。
  • 募集：活用事例を、11月30日までにフォームで受け付ける。選ばれたものは、追加の利用枠やクレジットの対象になりうる。
  • 研究用に限る：AlphaGenome と AlphaGenome 2 は、研究用で、臨床や診断への使用は、検証も承認もされていない、と明記している。
