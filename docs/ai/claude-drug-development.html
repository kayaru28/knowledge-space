Anthropic は2026年10月27日、創薬で AI の Claude を使った初期の成果を記事にまとめました。数か月にわたって6つの組織と協力し、自社でも筋ジストロフィーの研究を始めています。

示された事例はすべて Anthropic の記述で、ほとんどはヒトでの試験の前（前臨床）の段階です。薬として効くか、安全かが示されたわけではありません。

6つの事例

Anthropic の記事が示した事例（創薬の段階ごと）
組織段階内容と示された数字
Generate Biomedicines治療の形の設計固形がん向けに CAR-T 細胞療法の一部を短くする設計を、6人の科学者が Claude Code で提案。標準より約70%短い設計が、実験で受容体が約10倍作られ、腫瘍の細胞をより効率よく殺し、免疫細胞が長く活動した
Divergence Labs候補の探索食物アレルギーの薬の設計。Claude が設計計画を作り、ほぼ自律的に約1か月で約35,000の抗体の設計を作成。初期の試験で、IgE に結合する設計が3つ、引きはがす設計が20（うち3つは標準の薬より多く引きはがした）
BigHat Biosciences候補の最適化2つの候補について、約10週間に約1,010の変異体を作って試験。途中で標準の指標が誤解を招くと疑い、別の指標を提案して主な予測は成り立った。最良の版は結合が10倍以上強く、凝集が100倍以上遅い例もあった
Enveda製造の書類と申請1,061ページの試験で、人が見つけた11件をすべて指摘し、人が見逃した7件も指摘。確認の時間は25時間超から3時間未満。規制当局向けの書類の初稿は、4時間（手作業では約3か月）
The Column Group会社づくりClaude で小さなチームが多くの創薬計画を回す新会社 Pleiades を設立中。最初のスキルは45組の標的と疾患の組で評価
Bristol Myers Squibb治験の計画初期の薬の治験計画を評価し、成功の見込みを見積もる。2027年に拡大する予定。担当者は、通常は数日かかる分析の初稿が、ひとつの指示から出たと述べている

自社の取り組み：Mithril Medicine

  • Anthropic は、2種類の希少な筋ジストロフィーの治療を研究していた一人の会社 Mithril Medicine を買収しました。
  • 創業者は Claude で、11の外部の研究室との契約、手配、実験を整理し、運営の多くを任せていました。1つの病型の候補を、18か月未満で、アイデアからマウスでの有望な結果まで進めたと説明しています。
  • 創業者はいま Anthropic で研究を続けています。候補が持ちこたえれば、ヒトでの治験の開始は早ければ2028年の終わりです。

今後と提供の枠組み

  • 研究はまだ初期で、ほとんど前臨床です。治験の段階に進んだ組織とも組む予定です。
  • Claude Science（研究者向けの作業環境）と、生命科学者向けの Claude のクレジットを提供。
  • Life Sciences Verification Program：信頼できる組織に、安全策をゆるめた版の最も強力なモデルを提供する枠組み。生物学の研究を妨げうる制限を和らげるため、と説明しています。
  • ゲスト研究者の公募を始めています。

読むときの注意

  • すべて Anthropic の記事の記述です。各提携先の技術報告は読んでいません。
  • 数字は、取り組みの一部の指標です。「結合が10倍強い」「書類の確認が89%減った」は、薬としての有効性や安全性を示すものではありません。
  • 前臨床：ヒトでの試験の結果ではありません。記事自身が、ほとんどは前臨床だと述べています。
  • 設計の数と成果：Divergence Labs の約35,000の設計から見つかったのは「ヒット」（さらに調べる価値のある候補）で、薬ではありません。次の段階の結果は、記事に出ていません。

見方（筆者の整理）

  • 記事が強調するのは、設計を作る場面だけではなく、候補の最適化、製造の書類、治験の計画、会社の運営といった、周辺の作業にも AI を入れることです。
  • BigHat の事例のように、標準の指標が誤解を招くと見直した場面は、AI が単に答えを出すだけでなく、データの解釈の見直しにも使われた例として挙がっています。
  • 確かめるべきは、独立した評価と、臨床の段階の結果です。
