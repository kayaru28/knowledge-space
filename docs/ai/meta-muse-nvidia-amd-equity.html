Meta の株式発行と、NVIDIA・AMD の提携拡大：Muse を動かす計算基盤と、225億ドルの公募、そして「出資する」と「関心を示した」のずれ

2026年10月26日と27日に NVIDIA と AMD が発表した Meta との提携拡大と、Meta が SEC に提出した株式発行の目論見書補足から、Muse を支える計算基盤の中身、225億ドルの株式の公募と転換優先株の同時募集、NVIDIA と AMD などの出資の書かれ方の違い、まだ空欄の項目を、原本で整理する。

初回公開 2026-10-29 ／ 更新日 2026-10-29

ひとことで言うと

2026年10月26日と27日、NVIDIA と AMD は、Meta とのAI分野での提携を広げると発表しました。どちらも、Meta のAIエージェント「Muse」と、その計算基盤が中心です。同じ10月26日に、Meta は株式の発行について、SEC に目論見書補足（まだ価格が空欄の草案）を提出しています。

読みどころは、お金の書かれ方の違いです。NVIDIA と AMD は、それぞれ30億ドルと10億ドルを「出資する」と発表しました。一方、Meta の書類では、NVIDIA、AMD、Broadcom の3社は、合わせて最大50億ドルを買う「関心を示した」とされ、これは拘束力のないものです。なお、報道にある「最大950億ドル」という数字は、この補足書類には出てきません。

NVIDIA の発表（10月26日）

  • 範囲：Muse とそのモデルの仲間の、学習と推論の性能を上げるため、協力を広げる。作業の流れ全体を最適化して、性能を上げ、総保有コストを下げる狙い。
  • Meta の導入：次世代のAIエージェント向けに、NVIDIA の Vera Rubin と Vera CPU の導入を広げる意向。ネットワークに Spectrum-X Ethernet と BlueField-4 も使う。
  • 安全と監視：エージェントを安全に配置する「OpenShell」と、動きを監視する「Sentry」を使った協力も「検討する」という書き方。
  • 出資：「NVIDIA は、Meta の株式発行に30億ドルを出資する」と書いている。
  • Muse の評価：NVIDIA は、Muse のモデルとエージェントが、フロンティア級の評価の成績と、利用者の急増する取得（ダウンロード）を出している、と述べる。これは NVIDIA の説明。

AMD の発表（10月27日）

  • Helios：ラック単位のAIシステム「Helios」の初期の分が、Meta に設置され、試験中。近く、より広い展開を目指す。
  • EPYC：Muse の専用の計算環境を、AMD の EPYC プロセッサが支える。Meta は、複数世代で数百万個を導入していて、第6世代 EPYC の主要顧客でもある。将来世代の「Verano」でも協力する。
  • Instinct GPU：Meta で、学習、ランキング、推薦に実際に使われている。Meta の仕事向けに最適化した専用のGPUを導入する。次の世代（MI500 シリーズ）にも、この協力が反映される。
  • 初日から対応：Muse Spark Open は Instinct GPU で、Muse Glimmer は Ryzen AI 搭載のPCと Radeon GPU で、公開の初日から使える。
  • ソフト：PyTorch、Triton、ROCm の改良を、ほかの開発者も使える形で貢献している。
  • 規模：両社は、ギガワット規模のAIシステムの構築と展開に、製品計画を合わせている、と述べる。
  • 出資：「AMD は、Meta の株式発行に10億ドルを出資する」と書いている。

Meta が SEC に出した書類

Meta の目論見書補足（2026年10月26日付の草案）の主な内容
項目書かれていること
公募の金額先渡しの売り手が、クラスA普通株を225億ドル分売る。引受人には、30日間、最大33.75億ドル分を追加で買う選択権
価格公募の価格、引受の割引、先渡しの価格は空欄。10月23日の最後の取引価格は642.62ドル
資金Meta は、最初は資金を受け取らない。先渡しの契約の受け渡しのときに受け取り、使いみちは「一般的な事業目的」
受け渡しの期限Meta の裁量で、遅くとも2027年11月19日まで
希薄化受け渡しは、1株あたりの利益の希薄化をもたらす、と明記
主な引受会社Morgan Stanley と Goldman Sachs が共同の主幹事
同時の募集2億5,000万の「Series A 預託株式」（1株は、転換義務つき優先株の20分の1）を別の補足で募集する予定。優先額は預託株式1つにつき50ドル。この募集と公募は、互いに条件になっていない
  • 中心となる投資家：NVIDIA、AMD、Broadcom の3社が「同じ価格と条件で、合わせて最大50億ドル分を買う関心を示した」と書かれている。これは拘束力のある約束ではない、と明記している。
  • 優先株の金額：預託株式2億5,000万に、優先額50ドルを掛けると約125億ドルになる（筆者の計算）。書類は、この合計を書いていない。配当率の欄も空欄。

「出資する」と「関心を示した」のずれ

同じ出来事の、書き手による言い方の違い
書き手書き方
NVIDIA（発表）30億ドルを出資する
AMD（発表）10億ドルを出資する
Meta（SEC の草案）NVIDIA、AMD、Broadcom が、合わせて最大50億ドルを買う関心を示した。拘束力はない。個別の金額は書かれていない
  • 30億ドルと10億ドルを足すと40億ドル。Meta の書類の50億ドルは、これに Broadcom の分を加えた上限と読めるが、Broadcom の金額は、この書類にも発表にも書かれていない。
  • 企業の発表は意向を示す言い方で、書類は法的な位置づけを慎重に書く言い方。数字の食い違いではなく、書く場の違い。ただし、最終の金額は、価格が決まって募集が終わるまで確定しない。

まだ確認できていないこと

  • 報道にある「最大950億ドル規模」の資金調達：Meta の目論見書補足には、この数字がない。補足の対象は、225億ドルの公募と、優先株の同時募集。950億ドルの根拠は、この記事では確認できていない。
  • 公募の価格、株数、優先株の配当率、最終的な調達額。
  • Broadcom の金額と、3社の出資が実際に実行されたか。
  • AMD の Helios の本格的な展開の規模と時期。

読むときの注意

  • 草案：目論見書補足は「完成前」と明記された書類で、空欄が埋まるときに内容が変わりうる。この記事は、2026年10月29日時点で読める版にもとづく。
  • 企業の自己評価：NVIDIA の Muse の評価（フロンティア級の成績、取得の急増）や、AMD の「ギガワット規模」は、各社の説明。第三者の確認はこの記事では見ていない。
  • SEC の書類の取得：書類は直接取得できなかったため、本文の読み取りには要約ツールを使い、重要な数字（金額、期限、投資家の名前）は原文の引用で確認した。
  • 本稿は筆者の整理であり、投資の助言ではない。

見方（筆者の整理）

  • Muse を動かす計算基盤を、1社に頼らず、NVIDIA と AMD の両方（さらに自社チップ）で支える構図が、両社の発表から読める。Meta にとっては、調達先を分散させる意味がある。
  • 半導体会社が、顧客である Meta の株式を買う関心を示す形は、計算基盤の売り手と買い手の関係が、お金の面でもつながっていることを示す。需要の裏づけとして見るか、資金の循環として見るかは、立場によって分かれる。
  • 公募の価格が決まった後の書類で、金額と条件が確定する。それまでは、数字を確定したものとして扱わないのがよい。
