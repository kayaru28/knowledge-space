10月の最新AIモデル3つを比べる：Gemini 4 Argon、Muse Spark Open、DeepSeek V4.1-Flash

Google、Meta、DeepSeek の公式発表をもとに、2026年9月〜10月に出た3つのAIモデルを、提供形態、価格、動かすのに必要なもの、ライセンスの観点で整理する。性能の数字は各社の自己申告で、互いに比べられない。

初回公開 2026-10-19 ／ 更新日 2026-10-19

ひとことで言うと

2026年9月10日から10月17日にかけて、Google、Meta、DeepSeek がそれぞれ新しいAIモデルを出しました。Gemini 4 Argon は API で使うモデル、Muse Spark Open と DeepSeek V4.1-Flash は重みが公開されたモデルで、提供形態が違います。

性能の数字（ベンチマーク）は、各社が自社で公表したもので、条件も指標も違うため、横に並べて順位をつけることはできません。選ぶときは、提供形態、価格、動かすのに必要なもの、ライセンスを見ます。

価格と日程

各モデルの要点

Gemini 4 Argon（Google）

  • 10月13日に、API 経由で全世界に提供。Gemini API の有料ティア、Gemini for business、Google Antigravity で利用可能。無料ティアでは使えない
  • モデル ID は gemini-4-argon。入力は、テキスト、画像、動画、音声、PDF。出力はテキスト。最大出力は 65,536 トークン（long decode で 1,048,576）
  • 思考の設定は low、medium、high。Batch API、Flex、Priority に対応
  • サイバーセキュリティの防御者は、Fairwind Program に参加すると、サイバー関連のガードレールなしの版を使える
  • ベンチマークは、第三者の評価とされるものと、Google・パートナーの自己報告が混在している

Muse Spark Open（Meta）

  • 10月15日公開。重みは Meta の Hugging Face リポジトリにある
  • 総 816B、有効 42B の MoE。コンテキストは 1M トークン。入力はテキスト、画像、動画、音声。出力はテキストのみ
  • 推論強度は low、medium、high、xhigh から選べる。既定は xhigh
  • 推論エンジンは、SGLang、vLLM、Hugging Face Transformers、TensorRT-LLM、Unsloth、llama.cpp に対応
  • モデルカードの制限：不正確な回答の可能性、一部の言語では性能低下、量子化版での品質差、18歳未満は想定外

DeepSeek V4.1-Flash

  • 9月10日に発表。API では deepseek-flash を指定。552B の MoE で、入力に 8B、出力に 16B のアクティブパラメーターを使う構造
  • 前の世代と比べて、KV キャッシュは HBM が 1/4、SSD ストレージが 1/8 で済む
  • 10月17日に V4.1-Flash-1017 を公開。ベンチマーク性能の向上、タスク完了の高速化、出力の短縮を挙げる。API の呼び出し方法に変更はない
  • 旧モデル名（deepseek-v4-flash など）は V4.1-Flash に転送される。V4-Pro は段階的に廃止
  • Search & Fetch API：各 1,000 件の成功リクエストあたり $0.75。失敗や空の結果は課金されない

自分で動かす場合

重みが公開されたモデルでも、動かすには大きなメモリが要ります。Muse Spark Open のモデルカードには、必要な VRAM が書かれています。

ライセンスの確認

Muse Spark Open の重みは無償ですが、独自の「Muse Model License」の条件があります。製品やサービスで使うときに、確認する流れを整理しました。

選ぶときの観点

各社の発表を並べて読んだ上での、筆者の整理です。各社がそう述べているわけではありません。

  • 動かす場所: API で使うか、自分で動かすか。自分で動かすなら、メモリの要件を確認する（Muse Spark Open は 700GB 以上）。
  • 価格: Gemini 4 Argon は導入価格が11月末で終わる。DeepSeek はピークとオフピークで単価が違い、Search & Fetch は10月末から課金される。
  • ライセンス: Muse Spark Open は無償だが、表示の義務と、MaaS の条件がある。
  • 入出力: 音声や PDF の入力が要るか。出力は、確認できた範囲ではいずれもテキスト。
  • 数字の見方: ベンチマークは各社の自己申告で、条件も指標も違う。自分のタスクで試す。

用語メモ

オープンウェイト
モデルの重み（学習結果）が公開されていて、自分の環境で動かせるもの。ソースコードや学習データまで公開されるとは限らない。
MoE（Mixture-of-Experts）
複数の専門家（サブネットワーク）のうち、一部だけを選んで動かす構造。総パラメーター数より、有効パラメーター数が小さい。
VRAM
GPU が使うメモリ。モデルを動かすのに必要な量が、そのまま要件になる。
NVFP4、BF16
数値の表現形式。NVFP4 は小さく、BF16 は大きい。
コンテキスト
一度にモデルが扱える入力と出力の量（トークン数）。
KV キャッシュ
推論時に、過去の計算結果を保存しておく領域。
