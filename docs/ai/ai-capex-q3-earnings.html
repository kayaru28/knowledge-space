AI 投資が決算に表れた：Alphabet・Microsoft・Amazon の7〜9月期（クラウドは最大2倍の伸び、設備投資は約2.1倍、純利益の増減は別の理由）

2026年10月28日と29日に発表された Alphabet、Microsoft、Amazon の7〜9月期の決算の原本から、クラウド事業の伸び、設備投資の増え方、現金収支、純利益が増減した理由を、3社の数字を並べて整理する。

初回公開 2026-10-31 ／ 更新日 2026-10-31

ひとことで言うと

10月28日と29日に、Alphabet、Microsoft、Amazon が7〜9月期の決算を発表しました。3社とも、クラウド事業が大きく伸びました（Google Cloud +103%、Azure +48%、AWS +39%）。同時に、設備投資（現金ベース）は、3社の合計で前年同期の約2.1倍に増え、Alphabet と Amazon は、フリーキャッシュフローがマイナスになりました。

純利益の動きは、3社でばらばらでした（Alphabet −25%、Microsoft +32%、Amazon −2%）。ただし、原本を読むと、理由は設備投資の負担だけではありません。Alphabet は株式の評価損、Amazon は前年の Anthropic への投資益の反動、Microsoft は OpenAI への投資の損益が入っています。

約2.1倍

3社の設備投資（現金ベース）の合計。約784億ドルから約1,680億ドルへ（前年同期との比較。定義は各社で違う）

+103%

Google Cloud の売上の伸び（307億ドル）。Azure は+48%、AWS は+39%

6,770億ドル

Microsoft の商用の受注残（残存履行義務）。前年同期から+73%

−424億ドル

Amazon の過去12か月のフリーキャッシュフロー（前年は+148億ドル）

各社の発表から

Alphabet（10月28日）

  • 売上は1,276億ドル（+25%）。Google Services は963億ドル（+11%）で、検索は+12%。検索のクエリ数の伸びは、過去5年で最も高いと説明している。
  • Google Cloud は307億ドル（+103%）。営業利益は111億ドル（前年36億ドル）。企業向けの AI の基盤と AI の製品が伸び、TPU システムの販売も売上の伸びに寄与したと書いている。
  • 設備投資は514億ドル（前年240億ドル）。過去12か月で1,598億ドル。営業キャッシュフロー423億ドルを上回り、フリーキャッシュフローは−91億ドル（4〜6月期は−59億ドル）。過去12か月では+197億ドル。
  • 純利益は262億ドルで、前年の350億ドルより25%減った。営業利益は+30%で、減った理由は営業の外にある。株式への投資の損益が、前年の+107億ドルから、−87億ドルになった。この損失で、純利益が67億ドル、1株あたり利益が0.55ドル下がったと書いている。
  • 手元の現金と有価証券は2,651億ドル（2025年12月末は1,268億ドル）。7〜9月に、市場での売り出し（at-the-market）で、クラスA株を43億ドル、クラスC株を81億ドル分、発行した。
  • CEO の説明：Gemini 4 Argon と Carbon が最先端にある。自社モデルの API は毎分約320億トークンを処理（1年前の4倍超）。Gemini アプリは10億人に達した。

Microsoft（10月28日。2027会計年度の第1四半期）

  • 売上は923億ドル（+19%）、営業利益は459億ドル（+21%）、純利益は366億ドル（+32%）。
  • Microsoft Cloud は639億ドル（+30%。成長が加速したと説明）。Azure は+48%。商用の残存履行義務（契約済みで、まだ売上にしていない金額）は6,770億ドルで、+73%。
  • 設備投資（有形固定資産の増加）は394億ドル（前年194億ドル）。営業活動による現金は580億ドル（前年451億ドル）。
  • 純利益の+32%には、OpenAI への投資の損益が入っている。今期は純利益を2億ドル増やし、前年同期は31億ドル減らした。この影響を除いた（非GAAP）純利益は364億ドルで+18%。
  • Devices and Consumer の売上は155億ドル（−3%）で、Windows OEM と Devices が−22%。株主への還元は102億ドル。

Amazon（10月29日）

  • 売上は2,019億ドル（+12%）。AWS は460億ドル（+39%。約5年ぶりの速い伸びと説明）で、年換算で1,840億ドル。AWS の営業利益は178億ドル（前年114億ドル）。
  • 営業利益は281億ドル（前年174億ドル）、営業利益率は13.9%で、同社で最も高い。
  • 純利益は207億ドルで、前年の212億ドルから減った。同社は、前年の7〜9月期に、Anthropic への投資による税引前の利益95億ドルがあったことが主な理由と書いている。
  • 設備投資（有形固定資産の購入）は773億ドル（前年351億ドル）。過去12か月で2,152億ドル（前年1,201億ドル）。2026年の現金での設備投資は約2,200億ドルの見込みで、従来の見込みを維持した。
  • 過去12か月の営業キャッシュフローは1,683億ドル（+29%）。フリーキャッシュフローは−424億ドル（前年+148億ドル）。設備投資（受取分を差し引いた純額）が948億ドル増えたのが主因で、主に AI への投資を反映していると書いている。
  • 10〜12月期の見通し：売上2,400億〜2,470億ドル、営業利益285億〜335億ドル。
  • CEO の説明：AWS の売上の伸びは、2027年と2028年も40%超になる見込み。同社の AI 推論サービス Bedrock は、Fortune 500 の企業の支出が前年の約7倍、トークンの量が約17倍になった。Bedrock に、OpenAI、Anthropic、Moonshot AI などのモデルを追加した。

読むときの注意

  • 設備投資の定義は、各社で違う：Alphabet は「有形固定資産の購入」、Microsoft は「有形固定資産の増加」（ファイナンスリースによる分は別）、Amazon は「有形固定資産の購入」（フリーキャッシュフローは、売却や補助金の受取分を引いた純額）。3社の合計は、規模の目安。
  • 「クラウド」の範囲も違う：Google Cloud は事業区分、Microsoft Cloud は Azure のほか Microsoft 365 などを含む、AWS は事業区分。伸び率を、同じ物差しで並べることはできない。
  • 純利益は、投資先の評価損益に左右される：Alphabet の−25%は、営業利益が+30%のなかでの、株式の評価損による。Amazon の減少は、前年の Anthropic への投資益の反動。Microsoft の増加には、OpenAI への投資の損益が入る。AI の設備投資の負担だけで説明できない。
  • 受注残は、売上ではない：Microsoft の6,770億ドルは、契約済みの金額で、売上になる時期はさまざま。そのまま今期以降の売上になるとは限らない。
  • 今後の設備投資の見通しは、読んだ範囲では、Amazon の2026年の約2,200億ドルだけ。Alphabet と Microsoft の見通しは、決算説明会での発言で、この記事では確認していない。

用語メモ

設備投資
建物、サーバー、ネットワーク機器など、長く使う設備を買うための支出。決算では「有形固定資産の購入（増加）」として出る。
フリーキャッシュフロー
営業活動で得た現金から、設備投資を引いた金額。マイナスは、事業で稼いだ現金を、設備投資が上回っていること。
残存履行義務（RPO）
契約を結んだが、まだ売上にしていない金額。Microsoft は、商用の分を受注残の目安として出している。
営業利益
本業で稼いだ利益。株式などへの投資の損益は含まない。
TPU
Google が作る、AI 向けの計算用のチップ。
Bedrock
Amazon の AWS が提供する、複数の AI モデルを使えるサービス。
非GAAP
会計基準（GAAP）の数字から、特定の項目を除いた数字。Microsoft は、OpenAI への投資の損益を除いている。
