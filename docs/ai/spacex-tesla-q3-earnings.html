SpaceX と Tesla の7〜9月期決算：SpaceX は売上2.6倍で黒字転換、Tesla は売上横ばいで営業利益56%減、そして両社をつなぐ特別委員会

2026年10月20日の SpaceX と、10月21日の Tesla の7〜9月期の決算の原本（SpaceX の発表資料、Tesla の8-Kと10-Q）から、事業ごとの数字、投資の負担、両社の取引と資本関係、Tesla が設置した特別委員会について、確認できることと確認できていないことを整理する。

初回公開 2026-11-04 ／ 更新日 2026-11-04

ひとことで言うと

SpaceX は10月20日、7〜9月期の売上が146億ドル（前年同期の56億ドルの約2.6倍、+161%）、純利益が44億ドル（前年同期は11億ドルの赤字）だったと発表しました。伸びを引っ張ったのは、AI 事業を含む「SI」部門（売上76億ドル、前年同期比+830%）です。一方で設備投資は196億ドル（前年同期の約2.8倍）に膨らみ、その大半（164億ドル）が SI でした。

Tesla は10月21日、7〜9月期の売上が280億ドル（前年同期とほぼ同じ）、営業利益が7.18億ドル（前年同期は16.2億ドルで、約56%減）と発表しました。研究開発費が約1.7倍の27.6億ドルになっています。

Tesla の10-Qには、取締役会が、利害関係のない取締役による特別委員会を設置し、SpaceX との関係を深めること（企業結合を含む）を検討していると書かれています。成立の保証はなく、特別委員会の推薦と、必要な株主の承認が条件です。Tesla は SpaceX に蓄電池「Megapack」を売っていて、SpaceX の株式にも20億ドルを投資しています。

SpaceX の決算（10月20日）

  • 売上は146億ドル（+161%）。部門別では、宇宙（Space）が17.7億ドル（+6%）、通信（Connectivity）が52.5億ドル（+69%）、SI が75.6億ドル（+830%）。
  • 営業利益は27.9億ドルの黒字（4〜6月は1.4億ドルの赤字）。調整後 EBITDA（会社が定義した非GAAP指標）は88億ドル（前年同期の22億ドルから+306%）。
  • SI 部門：売上のうち、SI のソリューションとインフラが70.2億ドル（前年同期は3.6億ドル）、広告が5.4億ドル。会社は、クラウドサービスの契約の開始、Cursor の買収、Grok の企業への広がりを理由に挙げている。SI の営業利益は4.3億ドル（Cursor の買収に伴う株式報酬12億ドルを含む）。SI の設備投資は164億ドル。計算能力（公称）は1.7GW で、前年同期の0.6GW、4〜6月の1.4GW から増えた。
  • 通信部門：Starlink の個人向けの契約者は1,360万人（前年同期は720万人）。1人あたりの月額収入は69ドル（前年同期は83ドル）。個人向けの売上は31.2億ドル、企業・政府向けは21.3億ドル。営業利益は23.7億ドル（+99%）。
  • 宇宙部門：打ち上げは35回（顧客向け12回、自社向け23回）。Starship の第14回の飛行で、Starlink V3 の衛星26基を軌道に送った。営業損益はほぼゼロ（7百万ドルの赤字）で、研究開発費の増加が響いた。
  • Cursor の買収：2026年8月14日に完了。株式の評価額は600億ドル相当（会計上の取得対価は425億ドル）。買収後から9月30日までの売上への寄与は6.08億ドル。
  • 10月8日に、全米の800MHz帯の周波数免許を取得する契約を結んだ（完了は2027年上半期の見込み）。
  • 設備投資は合計196億ドル（SI が164億ドル、宇宙が16億ドル、通信が15億ドル）。

Tesla の決算（10月21日）

  • 売上は280.5億ドルで、前年同期（281.0億ドル）とほぼ同じ。自動車が205.6億ドル（前年同期は212.1億ドル）、エネルギー（発電・蓄電）が28.8億ドル（前年同期は34.2億ドル）、サービス・その他が46.1億ドル（前年同期は34.8億ドル）。
  • 営業利益は7.18億ドルで、前年同期の16.2億ドルから減った。営業利益率は約2.6%（筆者の計算）。
  • 費用の増え方：研究開発費が27.6億ドル（前年同期は16.3億ドル）、販売費・一般管理費が20.2億ドル（前年同期は15.6億ドル）。
  • 普通株主に帰属する純利益は7.87億ドル（前年同期は13.7億ドル）。
  • 1〜9月の設備投資は約130億ドル（前年同期は約61億ドル）。主に、AI を含む「SI」の基盤と工場の増設。営業活動によるキャッシュフローは約149億ドル。
  • 2026年9月30日の現金と短期投資は約454.5億ドル。

2社のあいだの関係（Tesla の10-Qから）

  • 特別委員会：Tesla の取締役会は、利害関係のない取締役からなる特別委員会を設置した。目的は、SpaceX との関係を深めること。方法には、企業結合（合併など）を含む。10-Qは、「取引にはメリットがありうるが、成立の保証はない」とし、取引には特別委員会の肯定的な推薦と、必要な場合の株主の承認が要ると書いている。
  • 取引：Tesla は SpaceX に蓄電池「Megapack」を売っていて、7〜9月に2.21億ドル、1〜9月に6.26億ドルの売上を計上した。9月30日時点の売掛金は7.29億ドル（まだ納めていない Megapack の前払いの請求を含む）、契約負債（前受け金）は6.48億ドル。ほかの取引は重要でないとしている。
  • 資本関係：Tesla は2026年3月に、20億ドルで SpaceX の普通株を取得した（もとは xAI の優先株への投資で、規制当局の承認を受けて SpaceX の普通株になった）。持ち分は1%未満。CEO が両社の CEO を兼ねるため、重要な影響力があると推定され、持分法で扱い、公正価値で評価している。7〜9月は1.42億ドルの損失、1〜9月は8.63億ドルの利益を計上した。
  • 取締役会が特別委員会を設置した時期や、委員の人数、検討の中身は、10-Qには書かれていない。

分かっていないこと

  • SpaceX 側の特別委員会：SpaceX の決算説明会で、SpaceX 側にも特別委員会があるという発言があったと報じられているが、公式の書き起こしを確認できていないため、この記事では扱わない。
  • 条件と時期：合併の条件、時期、株式の交換比率は、確認できる資料にない。10-Qは「成立の保証はない」と書くだけ。
  • Tesla の運営の数字（納車台数、FSD の契約数、Robotaxi の状況など）は、今回読んだ提出書類の範囲では確認していない。

読むときの注意

  • SpaceX の発表資料は、会社の自社資料で、監査前の数字。調整後 EBITDA は会社が定義した非GAAP指標で、通常の会計基準の利益とは違う。
  • 会社の区分（宇宙、通信、SI）は SpaceX の定義。前年同期との比較は、会社の開示のままの数字。事業の統合や買収（Cursor など）の影響を含む。
  • 約2.6倍（売上）、約2.8倍（設備投資）、約56%減（Tesla の営業利益）、Tesla の営業利益率（約2.6%）は、筆者の計算。
  • 本稿は筆者の整理であり、投資の助言ではない。

用語メモ

営業利益
本業で稼いだ利益。投資の損益などは含まない。
調整後 EBITDA
利息、税金、減価償却などを除いた利益に、株式報酬などの調整を加えた、会社が定義した指標。
SI
SpaceX と Tesla が、AI 関連の事業・開発を指して使う区分名。
持分法
持ち分が過半でなくても、重要な影響力がある投資先の損益を、持ち分に応じて自社の損益に取り込む会計の方法。
特別委員会
取引の当事者と利害関係のない取締役だけで作る委員会。取引条件の検討や、推薦をする。
Megapack
Tesla の大型の蓄電池。
契約負債
代金を先に受け取ったが、まだ商品やサービスを渡していない分。
