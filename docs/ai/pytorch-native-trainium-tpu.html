NVIDIA 以外の AI チップで PyTorch がそのまま動く：TorchNeuron（Trainium）と TorchTPU の公開、Oracle Cloud への Google TPU 導入

2026年10月20日前後に AWS と Google が公開した、PyTorch を自社チップで動かすオープンソースの実装（TorchNeuron、TorchTPU）の使い方と制限、各社が示した検証と性能の数字、10月27日に発表された Oracle Cloud への Google TPU 導入（2027年）を、公式の発表から整理する。

初回公開 2026-10-30 ／ 更新日 2026-10-30

ひとことで言うと

2026年10月20日前後に、AWS と Google が、自社の AI チップ（Trainium、TPU）で PyTorch をそのまま動かすための実装を、それぞれオープンソースで公開しました。AWS の TorchNeuron は公開ベータ、Google の TorchTPU は PyTorch の公式ブログで公開されています。どちらも、コードの書き換えを「デバイス名を替える」程度に近づけることを狙っています。

10月27日には、Oracle と Google が、2027年から Oracle Cloud で Google の TPU を提供すると発表しました。ただし、性能の数字はすべて、公開した会社自身のものです。独立した検証は、読んだ原本からは確認できませんでした。

背景：なぜ「PyTorch のまま」が要点なのか

  • TorchNeuron の公式ブログによると、研究者は実験したく、顧客は Trainium の性能を使いたい。学習と推論のライブラリは PyTorch の API で書かれ、新しい版が出続けています。PyTorch は数年かけて API をアクセラレータに依存しない形にし、独自のハードウェアを登録する公式の拡張点（PrivateUse1、torch.accelerator）を用意しました。TorchNeuron は、この拡張点の上に作られています。
  • TorchTPU の公式ブログによると、TPU はこれまで TensorFlow と JAX の環境と結びついてきました。2020年に PyTorch/XLA が出ましたが、コンパイルする範囲を明示する手直しが要る、コンパイル待ちが長い、通常の逐次実行（eager）に対応しない、といった課題があった、と Google は説明しています。
  • TorchTPU は2025年半ばに Google で始まり、Meta の PyTorch チームと共同で進められました。

TorchNeuron（AWS）：公開ベータ

使い方

モデルを .to('neuron') に置くと、Trainium で動きます。torch.compile は、バックエンドに neuron を指定します。torch.nn、torch.distributed、torch.profiler などの標準の API が、neuron のデバイスで動きます。PyTorch の自動読み込みで登録されるため、専用の import は要りません。対象は PyTorch 2.14 で、それより前の XLA ベースの torch-neuronx は、別の系統として提供が続きます。

実行方式

eager は、演算ごとに実行ファイル（NEFF）を作って動かします。torch.compile は、Dynamo で計算グラフを捕まえ、Neuron のコンパイラが NEFF にします。adaptive eager は、小さな部分グラフをまとめて作る実験的な方式で、既定では無効です。

独自のカーネル

NKI で、eager と torch.compile の両方に独自の演算を足せます。学習で使うには、backward 側の実装（register_autograd）が要ります。

制限と検証

  • 制限：eager で Neuron 向けの実装がない演算は CPU で動き、警告が出ます。torch.compile は、変換できない演算があると失敗します。float64 は float32 として動きます。初版で対応しないと決めたものに、疎テンソル、NestedTensor、順方向の自動微分、動的・記号的な形状などがあります。TorchAO と FP8 は非公開のベータで、次の版で一般提供の予定です。
  • 検証：Hugging Face の10万モデル（ダウンロード数で実際の利用の99.9%をカバーするとされる）を、縮小した構成で継続的に動かしています（2026年9月時点）。結果は図で示され、本文には数値がありません。PyTorch 本体のテスト（2026年8月）は約15.4万の結果があり、約6.9万が理由つきで飛ばされました。うち約3.9万が Neuron 側の意図した飛ばしで、最大は、Neuron 向けの実装がまだない演算の約2.2万です。
  • AWS の数字（Amazon Science）：キャッシュとコンパイルの共有で、1台の中で64プロセスに分けた大規模言語モデルの、最初の学習ステップまでの時間が約3分の1短くなりました。
  • 顧客の声（公式ブログに載った顧客の発言で、会社の主張です）：音声認識の Deepgram は、評価したベンチマークで、既存の GPU の基準より、1ドルあたり約60%多い入力音声の秒数を Trainium で処理できた、としています。

TorchTPU（Google）：開発中のオープンソース

設計の原則

PyTorch の実行環境に JAX を持ち込まない。eager を堅くする。torch.compile は Dynamo ベースで、JAX のコンパイルに近い性能を目指す。DDP、FSDP、DTensor などの分散に対応する。移植は model.to("cuda") を model.to("tpu") に替える程度を目指します。ただし、最高性能は、形状や分割が GPU 向けに偏っているため、それだけでは出ないと書いています。

対応の範囲

eager と compiled の両方。約450の Aten 演算。JAX/Pallas と Helion で独自のカーネルが書けます。Hugging Face の Transformers v5、Diffusers、Kernels と連携し、ダウンロード上位5,000のモデルが、そのまま動くと書いています。

Oracle Cloud への Google TPU 導入（10月27日）

  • 何が発表されたか：Oracle と Google が、Oracle AI World で、Oracle Cloud Infrastructure（OCI）が、Google 以外のハイパースケールのクラウドとして初めて Google の TPU を提供する、と発表しました。
  • 時期：2027年の暦年中に提供を始め、複数年かけて段階的に広げます。
  • 役割：Google が TPU を提供し、オープンソースのソフトウェアと共同で設計します。OCI は、大規模な展開に必要な電力、冷却、データセンターのネットワークを提供します。顧客は OCI の中で、ワークロードや性能・費用の要件に応じて TPU を選べます。
  • TPU の世代：発表文は第8世代の TPU 8t（学習向け）と TPU 8i（推論向け）を紹介していますが、OCI で提供する具体的な世代は書かれていません。
  • 会社の主張（独立した検証や測定条件はありません）：TPU 8t は、最先端モデルの開発サイクルを数か月から数週間に縮め、前世代より、ポッドあたりの計算性能が約3倍とされます。TPU 8i は、多数の専門化したエージェントによる反復の処理向けの設計です。
  • 想定する用途：高密度モデルと MoE の大規模な学習・ポストトレーニング、推論、エージェント、長い文脈の本番の推論。
  • 未確認：価格、提供するリージョン、台数。Oracle 側のページは取得できませんでした。

読むときの注意

  • 性能の数字は、AWS、Google、顧客それぞれのものです。条件が違い、直接は比べられません。
  • TorchNeuron は公開ベータ、TorchTPU も開発中と書かれています。
  • 切り替えが簡単になっても、最高性能には独自のカーネルが要る、と両社が書いています。TorchTPU の公式ブログは、デバイス名の変更だけでは最高性能は出ないと明記し、本番の最高性能には Pallas のカーネルを勧めています。TorchNeuron の顧客の発言も、繰り返し呼ぶ層で NKI のカーネルを書いたとしています。
  • Oracle の提供は2027年で、世代・価格・リージョンは書かれていません。Oracle のその他の発表は、扱っていません。

見方（筆者の整理）

  • 同じ週に、PyTorch のカンファレンスで、AWS と Google が、同じ「PyTorch の標準の拡張点に乗る」設計で、自社のチップを開きました。既存の PyTorch のコードとライブラリを持ち込みやすくすることが、チップ選びの障壁を下げる、という見立てです。
  • 一方で、「動く」ことと「速く安い」ことは別で、後者は個別のカーネルの調整と、実際のワークロードで決まります。各社の数字は自社の測定で、第三者による比較は、今回の原本には少ないです。
  • Oracle の件は、Google が TPU を自社のクラウドの外に出す動きです。ただし提供は2027年で、詳細は未発表です。
