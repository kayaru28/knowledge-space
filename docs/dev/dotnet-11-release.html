.NET 11 が公開された：C# 15 の共用型、MAUI の CoreCLR 化、そして .NET 8・9 のサポート終了

Microsoft が2026年11月10日に公開した .NET 11 の主な変更（C# 15、SDK、MAUI、ASP.NET Core、AI 関連）と、同日の .NET 8・9 のサポート終了、アップグレードの手順を、公式ブログをもとに整理する。

初回公開 2026-11-14 ／ 更新日 2026-11-14

ひとことで言うと

Microsoft は2026年11月10日、.NET 11 を公開しました。言語は C# 15（共用型と閉じた継承階層）、SDK は Native AOT の CLI ホストと常駐する MSBuild サーバー、MAUI は既定のランタイムを CoreCLR に変更しました。AI 向けには、MCP サーバーのテンプレートと Microsoft Agent Framework が加わりました。

.NET 11 は標準期間サポート（STS）で、サポートは2年です。同じ日に、.NET 8 と .NET 9 のサポートが終了しました。

  • STS と LTS の品質・保守の方針は同じで、違うのは期間だけです。
  • .NET 8 または 9 を使っている場合、修正を受け続けるには、サポートされている版へ移ります。発表文は、最新の機能なら .NET 11、LTS の期間が合うなら .NET 10 を案内しています。
  • .NET MAUI は、.NET の STS・LTS とは別の、独自のサポート方針に従います。

主な変更

C# 15

共用型（union）は「宣言した型のどれか1つ」を表し、switch 式で取りこぼしを検査します。閉じたクラスは、直接の派生を宣言したアセンブリの中に限ります。ほかに、コレクション式の引数、拡張インデクサー、ラベル付きの break と continue

SDK

Native AOT の CLI ホストが既定で有効。MSBuild サーバーが常駐。NuGet に、公開から一定期間が過ぎたパッケージだけを選ぶ設定（脆弱性の確認の代わりではない、と明記）

ランタイム

JIT と Native AOT の改善。クラッシュ時の報告が Linux と macOS にも。Runtime Async はプレビュー機能

.NET MAUI

既定のランタイムを CoreCLR に。Native AOT は選択式で、Android は実験的。Compatibility パッケージは含まれなくなった

ASP.NET Core と Blazor

非同期の検証、OpenAPI 3.2 が既定、SignalR の認証の更新、Blazor の CacheView。エージェント向けの Blazor AI コンポーネントは実験的

AI 関連

MCP サーバーのテンプレート（dotnet new mcpserver）、Microsoft.Extensions.AI、Microsoft Agent Framework、.NET Skills

ライブラリとデータベース

  • ライブラリ：Zstandard 圧縮、プロセス実行の API の拡充、メモリ上のストリームの4つのアダプター、System.Text.Json の共用型と JSON Lines への対応、LINQ の FullJoin。
  • Entity Framework Core 11：不要な結合の削減、GroupBy の変換の改善、FullJoin への対応。SQL Server のベクトルインデックスと近似ベクトル検索は実験的です。EF Core 11 は .NET 11 が必要です。
  • F# 11：コンパイラのメモリ使用量の改善と、並行の非同期処理の上限の指定。
  • Windows：新しいアプリには WinUI 3 を推奨。Windows Forms に、新しい外観のモード（選択式）。

アップグレードの手順（発表文の案内）

  1. global.json で SDK を固定していれば更新し、開発機とビルド機に同じ SDK を入れます。
  2. 対象フレームワークを .NET 11 に変え、パッケージとワークロードを合わせます。
  3. 破壊的変更（最低 CPU 要件の更新を含む）を確認します。SDK を入れただけでは、アプリの対象は変わりません。
  4. 実際の負荷で、テストと計測をします。公開方式、コンテナの基本イメージ、ネイティブの依存、配置先も確認します。
  5. リリース候補から上げる場合は、最終版に更新します。

読むときの注意
