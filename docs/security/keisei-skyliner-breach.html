スカイライナーの座席予約システムに不正アクセス：京成電鉄が、最大約337万件のお客様情報が取得された可能性を公表、予約システムの利用は停止中

京成電鉄が2026年11月13日に公表し、11月16日に追記した、スカイライナー座席予約システムへの不正アクセスを、公式のお知らせから整理する。11月11日深夜の不正アクセス、最大約337万件、対象の項目、パスワードの扱い、予約システムの停止と窓口での発売。

初回公開 2026-11-19 ／ 更新日 2026-11-19

ひとことで言うと

京成電鉄は、2026年11月11日（水）深夜に、スカイライナー座席予約システムへの第三者による不正なアクセスがあり、スカイライナーチケットレスサービスと e-ticket サービスのお客様情報が取得された可能性がある、と公表した。件数は最大約337万件。

対象の項目は、ユーザーID、パスワード、カナ氏名、電話番号、メールアドレス、生年月日、性別、国籍。パスワードは暗号化（ハッシュ化）されているので、第三者によって復元されることはない、としている。

8項目

対象の項目（ID、パスワード、カナ氏名、電話番号、メール、生年月日、性別、国籍）

停止中

スカイライナー座席予約システム全般（再開時期は未公表）

京成の対応

  • 対象のお客様には、後日、登録されているメールアドレス宛に個別に連絡する。
  • セキュリティ強化のため、スカイライナー座席予約システム全般の利用を停止している。再開の時期は、書かれていない（「しばらくお待ちください」）。
  • 駅の窓口と券売機では、引き続きスカイライナー券を発売している。

読むときの注意

  • 読んだのは、2026年11月13日付で、11月16日に追記された版。追記の前後でどこが変わったか（対象のサービスや項目が広がったか）は、初版を読んでいないので未確認。
  • 不正アクセスの方法、原因、取得された期間、実際に取得されたかどうか（「可能性がある」としている）は、書かれていない。
  • 最大約337万件は、件数で、人数ではない。同じ人の複数の登録が含まれるかは、書かれていない。

見方（筆者の整理）

  • 件数は、国内の最近の漏えいの中でも大きい部類。氏名、電話番号、メール、生年月日、性別、国籍がそろうと、本人を装う連絡（フィッシング）に使われやすい、という一般的な懸念がある（これは筆者の整理で、京成の発表に書かれていることではない）。
  • パスワードを暗号化（ハッシュ化）していると明記しているが、強度（方式）は書かれていない。ほかのサービスと同じパスワードを使っている人は、変更しておくのが無難。
  • 予約システム全体を止め、窓口と券売機に切り替えている。空港への移動に関わるサービスなので、停止の長さが利用者への影響として大きくなる。
