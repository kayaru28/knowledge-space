冷蔵設備の管理画面がインターネットに開いていた：フランスで相次いだ侵害と、CERT-FR の呼びかけ

2026年10月、フランスで店舗の冷蔵設備を遠隔から管理する装置への侵害が相次いだ。CERT-FR が求めた手順、メーカーのお知らせ、攻撃の前にインターネットから開けた管理画面の数と、その多くが弱点を抱えたまま半年以上開いていたことを、CERT-FR の注意喚起と IPinfo の走査から図で整理する。

初回公開 2026-10-23 ／ 更新日 2026-10-23

ひとことで言うと

フランスで、店舗の冷蔵・冷凍設備を遠隔から管理する装置への侵害が相次ぎました。フランスの政府のセキュリティ機関 CERT-FR は、2026年10月12日に注意喚起を出し、Danfoss の AK-SM・AK-SC と、Copeland と Dixell の XWEB の侵害を「多数」把握しているとしました。管理の画面をインターネットに出すこと自体が良い慣行に反するとして、まずインターネットから外すよう求めています。

IP アドレスのデータ会社 IPinfo の走査では、攻撃の5日前、Danfoss の管理画面がインターネットから開ける状態で世界に2,528台あり、その半分以上の1,331台がフランスにありました。その85%は、知られた弱点を抱えたままでした。

CERT-FR が求めたこと

注意喚起（CERTFR-2026-ALE-012）は、10月12日に出され、13日に Copeland と Dixell の XWEB を対象に加え、16日に推奨を更新しました。攻撃の活動は「おそらく続いている」としています。侵入の方法や攻撃者は、明らかにしていません。

Copeland（Dixell のブランドを持つ会社）も10月14日にお知らせを出し、販売とサポートが終わった XWEB EVO の世代に脆弱性があることを認めました。すぐにインターネットから外し（ポートの転送や公開の IP アドレスへの直結をしない）、遠隔の操作は VPN で行うこと、後継の XWEB PRO へ移る計画を立てることを求めています。XWEB PRO も、インターネットに出さないよう書いています。

攻撃の前、管理画面はどれだけ開いていたか

IPinfo は、IPv4 のインターネットを毎週走査しています。攻撃の5日前の10月6〜7日の走査で、Danfoss の管理画面（StoreView）が開いたアドレスは、世界で2,528ありました。フランスは1,331で、ほかの72の国と地域を合わせた1,197より多い数です。

多くが、知られた弱点を抱えたまま、半年以上開いていた

IPinfo は、管理画面に出るソフトウェアの作成日などから、どの修正が入っているかを分類しました。フランスの1,331のうち、Danfoss がサポートを終えた古い装置が527、新しい装置でも修正が足りないものが609（2023年の修正がないもの280、2025年の修正がないもの329）で、知られた修正がすべて入っていたのは195だけでした。ほかの国でも弱点のある割合は84%で、フランスだけが更新を怠っていたわけではありません。台数が多かったのです。

開いていた期間も長く、1,331のうち1,019は、半年前の3月30日にも同じアドレスで開いていました。修正がすべて入った新しい装置の割合は、この半年で14%から24%に上がっただけでした。

Copeland と Dixell の XWEB も、同じ走査で世界に1,611ありましたが、フランスは70でした（イタリアが467）。フランスでは攻撃の後に20まで減りました。

なお、管理画面がインターネットから開けることは、そこから侵入できることを意味しません。どの弱点が使われたかは、誰も明らかにしていません（IPinfo）。

見方

冷蔵の管理装置は、業者が遠隔から見守るために、店舗の回線からインターネットに出されていました。IPinfo によると、フランスの管理画面の98%は、データセンターではなく通信会社の回線の上にありました。サポートが終わった機器が、そのまま開いていたことが、今回の土台になりました。CERT-FR の答えは「まず外す。遠隔の操作は VPN で」です。保険の契約の条件が、外すことの妨げになりうる点にも触れています。日本でも、ビルや店舗の設備の管理画面がインターネットに出ていないか、サポートが終わった機器が残っていないかを確かめる価値があります。

CERT-FR

Danfoss の、店舗の冷蔵・冷凍設備をまとめて管理する装置のシリーズ。

インターネットのアドレスに順に接続し、何が応答するかを調べること。
