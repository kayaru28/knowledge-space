今月の重要な脆弱性（2026年10月）：悪用が確認されたものから対応する

JPCERT/CC と IPA の注意喚起・週次レポートから、悪用が報告されている7製品・9件の脆弱性を整理し、公開の経緯と、対応の優先順位、侵害調査の要点をまとめる。悪用は確認されていないが深刻度が高い Linux カーネルの PwnEscape も、仕組みを図で示す。

初回公開 2026-10-19 ／ 更新日 2026-10-25

ひとことで言うと

2026年9月中旬から10月中旬にかけて、JPCERT/CC と IPA が注意喚起や週次レポートで取り上げた脆弱性のうち、悪用が報告・確認されているものは9製品・12件です（10月23日に3件を追加）。対応は、悪用が確認されているものから順に行います。

注意したいのは、回避策が提供されていない製品があることです（NetScaler、Cisco Secure Email Gateway）。また、侵害の痕跡が消される可能性が示されている製品もあります（Cisco Secure Email Gateway、SiteGuard Server Edition）。更新するだけでなく、すでに侵害されていないかの調査も必要です。

10月20日追記：悪用は確認されていないものの深刻度が高いものとして、Linux カーネルの PwnEscape（CVE-2026-99999）を加えました。仮想マシンの中から、ホスト側の Linux のメモリを読み出せるもので、仮想マシンを動かすホストの管理者は、カーネルの更新が必要です。

10月21日追記：サポートが終わった機器の脆弱性として、楽天モバイルのスマートフォン4機種（Rakuten Mini など）を加えました。修正は出ないため、使うのをやめて、ほかの製品に乗り換えるよう案内されています。

10月23日追記：10月21日の週次レポートで悪用が確認されたとされた3件（Cisco Secure Email Gateway の別の脆弱性、BeyondTrust Remote Support、Ivanti Connect Secure）を加えました。

10月25日追記：悪用は確認されていないものの深刻度が最大のものとして、GitLab の CVE-2026-110264（CVSS 10.0。認証なしで、サーバー上でコードを実行されるおそれ）を加えました。自分で運用している GitLab は、10月21日の緊急パッチ（19.5.1、19.4.3 など）への更新が必要です。

検知ルールで見張る

GitLab.com は更新済みです。GitLab Dedicated も、19.3.5-internal0 と 19.4.2-internal0 以降なら、対応の必要はありません。

JPCERT/CC の週次レポートとの関係：JPCERT/CC の10月21日の週次レポートも、「GitLab に複数の脆弱性」を取り上げました。GitLab 19.4.2 の修正のうち、整数オーバーフローの脆弱性（CVE-2026-97229）について、JPCERT/CC は、概念実証コードが公開されていることを確認しています。10月21日の緊急パッチの CVE-2026-110264 とは、CVE の番号が別です。

対応の考え方

注意喚起の内容を並べて読んだ上での、対応の流れの整理です。各機関がそう述べているわけではありません。

侵害調査で示されている要点

NetScaler

Mandiant と GTIG の報告では、確認された侵害事例で、Web シェルの設置や、侵害後のアクセス維持を目的とした活動がありました。

  • Web サーバーの設定ファイル（/etc/httpd.conf）の不審な変更
  • VPN 関連ディレクトリの不審なファイル
  • DTLS のハンドシェイク失敗、NSPPE プロセスの異常終了
  • /tmp の不審なファイル、/bin/sh の不審な SUID 権限

Cisco Secure Email Gateway

root 権限で攻撃が成功した場合、ログや痕跡が削除されている可能性があります。製品上のログだけでなく、周辺機器などのネットワークログと突き合わせて調べます。

JPCERT/CC は、別の脆弱性（CVE-2025-20393）を悪用した侵害が国内で発生したことを確認しています。

SiteGuard Server Edition

開発者によると、アップデートの完了後に、侵害の痕跡が削除される可能性があります。

該当バージョンを使っている場合は、Web 管理画面で「診断情報」を取得し、攻撃の痕跡を保全してからアップデートします。

Microsoft 10月の更新

  • 公開：10/14（JPCERT/CC、IPA）

  • Windows Update などで適用。再起動が必要になる場合がある

Movable Type

  • 公開：IPA 10/7（JVN#91153973）。悪用の記載はない

この記事について

2026年10月25日時点の情報です（10月23日に、10月21日の週次レポートの3件を、10月25日に GitLab の件を追加）。状況は更新されていくため、最新の内容は各開発元の情報で確認してください。

修正バージョンの番号など、注意喚起に明記されていない項目は、開発元の最新情報で確認する必要があります。

ここで取り上げたのは、JPCERT/CC と IPA が10月中旬までに取り上げたもののうち、本文を直接確認できたものです。Linux の Copy Fail（IPA、CVE-2026-31431）は、5月の注意喚起で10月の更新がないため、今月の対象には入れていません。報道で伝えられた別の脆弱性は、一次情報を確認できていないため、扱っていません。

内容は、JPCERT/CC と IPA の資料をもとに、独自に整理したものです。PwnEscape は、CVE の記録、発見者、Vercel の公表をもとにしています。関連する話題として、国内で相次ぐ不正アクセスによる情報漏えいがあります。
