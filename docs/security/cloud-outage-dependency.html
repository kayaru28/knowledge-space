クラウドが止まると何が止まるか：ロンドンのゾーンの電源障害と、IDCFクラウドのランサムウェア被害

2026年10月の Google Cloud のロンドンのゾーンの電源障害と、IDCFクラウドのランサムウェア被害を、止まった範囲、時系列、取り出せたデータの数で比べ、ゾーンやリージョン、バックアップの備えが何に効いたかを公式の発表をもとに図で整理する。裁判所の mints の不調も扱う。

初回公開 2026-10-22 ／ 更新日 2026-10-22

ひとことで言うと

2026年10月、クラウドが止まる出来事が続きました。ただし、止まり方はまったく違います。

10月20日の Google Cloud では、ロンドンのリージョンの中の1つのゾーンで電源の障害が起き、約8時間、そのゾーンのサービスが使えなくなりました。影響が出た製品は38にのぼります。一方、10月7日からの IDCFクラウドでは、ランサムウェア攻撃で東日本リージョン1の4つのゾーンが被害を受け、495の企業・自治体のデータが、取り出しや復元が困難な見通しとされました。

前者は設備の故障で、ゾーンを分けて置けば避けられる種類の障害です。後者は事業者の基盤への攻撃で、同じリージョンの複数のゾーンが一度に被害を受けました。どこに、どんな写しを持っておくかで、取り戻せるものが変わります。

リージョンとゾーン

クラウドの事業者は、サービスを地域ごとの「リージョン」に分け、リージョンの中をさらに設備が独立した「ゾーン」に分けています。Google の説明では、リージョンは3つ以上のゾーンから成り、3つ以上の物理的なデータセンターに置かれます。そして「ゾーンは、リージョンの中の1つの障害単位とみなすべき」としています。

Google は、高い可用性のために、アプリケーションをリージョン内の複数のゾーンに置くこと、リージョン全体を失う場合に備えて別のリージョンでも動かせるよう計画すること、データを別のリージョンに複製することを勧めています。

Google Cloud：ロンドンの1つのゾーンの電源障害

障害は日本時間の10月20日 15:08 に始まりました。最初の公表は約2時間半後で、そのときは原因も回避策も示されていません。原因が「電源の事象」と公表されたのは開始から約5時間後で、その時点で電源はすでに解消していました。

影響が出た製品は38です。仮想マシン（Compute Engine）やディスク（Persistent Disk）、Kubernetes Engine のような土台のサービスに加えて、Cloud SQL、Spanner、BigQuery、Pub/Sub、Cloud Storage、ロードバランサ、VPC など、その上に作られたデータベースや分析、ネットワークのサービスにも及びました。

筆者の整理：1つのゾーンの電源から38の製品に影響が出たのは、多くのサービスが同じ土台の上で動いているためです。Google 自身が勧めるとおり複数のゾーンに分けて置いていれば、避けられる種類の障害でした。ただし、リージョンの一部のサービスでもエラーの増加やネットワークの問題が出ています。また、回復のときは既存の処理が優先され、新しい処理はしばらく作れませんでした。障害が起きてから別の場所に移す、という方法は、そのとき使えるとは限りません。

IDCFクラウド：ランサムウェアによる被害

IDCFクラウドでは、10月7日の午前3時40分ごろに障害が起き、同じ日のうちにランサムウェア攻撃によるものと判明しました。IDCフロンティアは、二次被害やデータ漏えいを防ぐため、東日本リージョン1をネットワークから遮断し、システムを止めています。

第3報の時点では、被害を受けた4つのゾーンのデータは、取り出しや復元が困難な見通しとされ、復元できるのは利用者自身が持つバックアップからだけとされました。その後の第5報で、スナップショット機能を使っていた利用者については、バックアップデータを取り出せることが確認されています。

被害のなかったゾーンやリージョンにも影響は及びました。外部からアクセスできる管理コンソールが止まったため、仮想サーバーの起動や停止は、利用者の要望に応じて IDCフロンティアが代行しました。バックアップの機能も一時止まり、10月18日に安全を確認して再開しています。スナップショット機能は、まだ止まったままです。

裁判所の mints：1日ほど不安定な状態

民事裁判の書類をオンラインで出すシステム「mints」では、10月15日の午前9時ごろから、サインインできない、事件が表示されない、記録の一覧の画面が表示されないなど、不安定な状態が続きました。裁判所のお知らせでは、10月16日の午前9時の時点で同じ事象は確認されておらず、支障なく使える状態になったとしています。原因は書かれていません。
