信用金庫の共同システム障害（11月6日）：西日本の信用金庫で、窓口とATMが約5時間半止まった

2026年11月6日13時27分から19時05分まで、しんきん共同システムの障害で、西日本エリアの信用金庫の窓口とATMなどが使えなくなった件を、しんきん共同センターなどの発表から整理する。原因はシステム機器の故障で、サイバー攻撃ではないとしている。

初回公開 2026-11-06 ／ 更新日 2026-11-06

ひとことで言うと

2026年11月6日13時27分、信用金庫の共同システム「しんきん共同システム」で障害が起き、西日本エリアの信用金庫の窓口業務とATMなどが使えなくなった。19時05分に復旧作業が完了し、全てのサービスが使えるようになった（約5時間半）。原因はシステム機器の故障で、サイバー攻撃ではないことを確認した、としている。

約5.6時間

障害が続いた時間（11月6日13時27分〜19時05分）

1件

公表された原因（システム機器の故障。サイバー攻撃ではない）

時系列（発表）

  • 11月6日 13時27分：「しんきん共同システム」で障害が発生。最初の発表では13時35分と書かれていたが、復旧の発表で13時27分に訂正された。広島信用金庫は「13時30分頃から」と書いている。
  • 発生中：西日本エリアの信用金庫で、窓口業務やATMなどの各種サービスが休止。広島信用金庫は、オンライン端末、為替、ATM（コンビニATMを含む）などが使えないと書き、大阪シティ信用金庫は、窓口・ATM・インターネットバンキング・他行のキャッシュカードによるATM取引など、勘定に関わる全ての取引が使えないと書いた。急ぎの振り込みは、信用金庫以外の金融機関を使うよう案内している。
  • 11月6日 19時05分：復旧作業が完了。西日本エリアの信用金庫で、ATMなど全てのサービスが使えるようになった。

原因について

  • 発表されたのは、「システム機器の故障によるもの」で、サイバー攻撃に起因するものではない、という点だけ。どの機器か、なぜ止まったか、なぜ全体に広がったかは、読んだ発表には書かれていない。
  • 当初の発表では「サイバー攻撃に起因するものではないと考えております」、復旧の発表では「確認している」と書き方が変わっている。

読むときの注意

  • 「西日本エリア」とだけ書かれ、対象の信用金庫の数や名前の一覧は、読んだ発表にはない。
  • 件数（影響を受けた取引や口座の数）、再発防止策は、読んだ範囲では未公表。

見方（筆者の整理）

  • 信用金庫は、各金庫が独自にシステムを持つのではなく、共同のセンターを使っている。そのため、1か所の機器の故障が、多数の金庫の窓口とATMに同時に及んだ。
  • 同じ6日に、国内では不正アクセスの漏えいの公表が続いていたが、この障害は攻撃ではなく機器の故障だった。止まった原因が攻撃かどうかを、発表がすぐに示している。
  • 利用者側の手当ては、他の金融機関を使う、という案内に限られた。共同システムの障害は、利用者が自分で避ける手段が少ない。

用語メモ

しんきん共同システム
信用金庫が共同で使う、勘定（口座の取引）などのオンラインシステム。しんきん共同センターが運営・管理する。
勘定系
口座の残高や入出金など、金融機関の基幹の取引を扱うシステム。

この記事について：2026年11月6日時点の情報です。内容は、全国信用金庫協会・しんきん共同センター・信金中央金庫の発表（11月6日の2件）と、大阪シティ信用金庫・広島信用金庫の告知をもとに、独自に整理したものです。
