UEFI ファームウェアの部品 EDK II の PXE ドライバの欠陥（CVE-2026-97631）：OSが起動する前に、ネットワークからコードを動かせる条件と、公式の勧告に書かれたこと

TianoCore（EDK II）が2026年10月22日に出した勧告 GHSA-99cj-7hg9-mp4m と修正の取り込みから、ネットワーク起動（PXE）の最中にICMPエラーを受けて起きるバッファあふれ、攻撃に必要な条件、影響、修正の状況、発見者を整理する。

初回公開 2026-10-29 ／ 更新日 2026-10-29

ひとことで言うと

パソコンやサーバーの起動を担う UEFI ファームウェアの共通の部品「EDK II」の、ネットワーク起動（PXE）のドライバに欠陥が見つかりました（CVE-2026-97631）。ネットワーク起動の最中にICMPのエラーメッセージを受けると、メモリが破壊され、条件がそろえば、OSが起動する前に攻撃者のコードが動く可能性があります。評価は CVSS v4 で 9.5（Critical）です。

ただし、起きるのは PXE で起動している最中だけです。公式の勧告に書かれているのは EDK II の部品の欠陥で、どの機器が実際に影響を受けるかは、機器メーカーごとの確認が必要です。

攻撃に必要な認証

何が起きるのか

  1. 機器がネットワーク起動（PXE）を始めると、ドライバ（NetworkPkg/UefiPxeBcDxe）は、ICMPのエラーメッセージを受け取る要求を開いたままにします。
  2. 受けたメッセージを、ドライバの内部の 504バイトの固定の欄に写します。
  3. IPv4 と IPv6 の両方の処理で、長さの扱いが誤っています。504バイトより長いメッセージでも写し続け、しかも書き込み先の位置を、1回分ではなく累計の長さで進めるため、欄の外に、攻撃者が与えたバイト列が書き込まれます。
  4. 受信の経路の前の段階に、メッセージの長さを制限する処理はありません。

影響（勧告の説明）

勧告に書かれた攻撃の条件と結果
項目内容
攻撃者認証なし。機器のIPアドレス宛てに、単独のICMPエラーメッセージを届けられればよい。どれだけ離れたネットワークからでもよい
いつ機器が PXE で起動している間（IPv4 でも IPv6 でも）。この時間が攻撃できる窓
結果 1ドライバのデータが決まって壊れ、DXE のコアで CPU 例外が起きる。次のICMPエラーで起動が止まり、OSの導入や復旧ができなくなる
結果 2起動するファームウェアのビルドを知っている攻撃者が、同じパケットに偽のイベントを仕込むと、DXE の段階（リング0、OSの安全機能が存在する前）で攻撃者のバイト列が実行される

勧告は、この段階では Secure Boot も測定つきの起動も、OSの部品をまだ確認も測定もしていない、と説明しています。

修正と状況

  • 修正：プルリクエスト #13302。ICMPエラー処理に境界の確認を加え、書き込み位置の計算を直しました。大きすぎるメッセージは、欄が満杯になったら切り捨てます。単体テストは、修正前は失敗し、修正後は通る、と書かれています。
  • 取り込み：プルリクエストは「マージ済み」と表示されています。ページ内の日付の表示が2通りあり、取り込みの日は確認できていません。
  • 勧告のページの記載：影響を受ける版は「2026年9月14日時点の EDK II master」、修正版は「現時点でなし」です。修正の取り込みの表示と、勧告の記載が食い違って見える理由は、確認できていません。
  • 発見：勧告は、Anthropic の研究者と Google の研究者が欠陥を見つけ、推奨の修正を提供したことに謝意を述べています。

読むときの注意

  • 影響を受ける機器の範囲：勧告の説明は EDK II の PXE ドライバに限られます。どのメーカーのどのファームウェアが対象か、更新が出ているかは、この記事では確認していません。機器メーカーの案内が必要です。
  • 悪用の有無：勧告には、実際に悪用されたとは書かれていません。
  • 攻撃の条件：PXE で起動している最中であること、ICMPのメッセージが機器に届くこと、そして実行まで進めるには対象のファームウェアのビルドの情報が要ること、がそろったときの話です。
  • 報道の数字や説明：「何年前からある欠陥か」「影響を受ける範囲の広さ」といった説明は、一次情報で確認できていないため載せていません。

見方（筆者の整理）

  • 起動の前の段階は、OSの安全機能がまだ動いていないので、そこで動くコードは、あとから見つけにくいのが難しいところです。この欠陥は、長さの確認の誤りという基本的な種類のものです。
  • 勧告が示す対処は修正のコードで、実際の機器では、機器メーカーが出すファームウェアの更新が必要になります。更新の有無は、この記事では確認していません。
