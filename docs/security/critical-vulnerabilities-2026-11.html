2026年11月1日〜20日に、JPCERT/CC の週報（11月11日号と18日号）、JPCERT/CC の注意喚起、IPA の重要なセキュリティ情報が取り上げた脆弱性を整理します。まず、悪用や攻撃の記述があるものを挙げます。Microsoft Outlook の CVE-2026-124194（Microsoft が悪用を公表）、Airbyte、Atlassian Confluence Data Center、Zyxel GS1900 シリーズ、Google Chrome などです。

11月18日〜20日の公表：NGINX、Java、PHP

NGINX（IPA、11月19日）

F5 が、11月18日に複数の脆弱性を公表した。CVSS v4.0 で 9.2（Critical）と評価されたのは、CVE-2026-123007、CVE-2026-123633、CVE-2026-121810、CVE-2026-123634、CVE-2026-113425の5件。影響は、使う機能や設定で変わる。NGINX Open Source は、NGINX 1.30.7 と 1.31.9 で修正された。HTTP/2 の一時的な無効化は、CVE-2026-123007 と CVE-2026-123633 の暫定の対応として案内されているが、HTTP/3、プロキシ、メールプロキシの脆弱性も含まれるため、5件すべての対策にはならない。ディストリビューションのパッケージは、バージョンの表記が違ったり、修正がバックポートされたりするため、番号だけで判断しない

Oracle Java SE（IPA、11月18日）

11月18日（日本時間）に、更新プログラムが公表された。ネットワーク経由で攻撃を受ける可能性がある脆弱性（CVE-2026-114938）が報告されており、IPA は、影響が大きいとして、早急な更新を求めている。対象は、サポート中の Java SE 27.0.1.0.3、25.0.5.0.3、21.0.13.0.3、17.0.21.0.3、11.0.33.0.3、8 Update 511b33（perf を含む）

PHP（IPA、11月19日・20日）

The PHP Group が、2026年11月19日に、PHP 8.2.36、8.3.37、8.4.28、8.5.13 を公開した。セッション処理、リクエスト処理、メモリ管理などの脆弱性で、特定の条件の任意のコード実行、リクエストスマグリング、署名検証の回避などを含む。事前の予告は、最高の深刻度（Critical）の脆弱性が、既定とは異なる設定や一般的でない構成で影響する、と説明していた。ただし IPA は、これだけで、すべての脆弱性を既定の設定なら影響を受けないと判断しないよう求めている

11月の月例の更新（Microsoft）

  • マイクロソフトは、2026年11月11日（日本時間）に、月例のセキュリティ更新プログラムを公開した。JPCERT/CC の注意喚起（JPCERT-AT-2026-0035）と IPA は、悪用が公表された脆弱性として、CVE-2026-124194（Outlook のなりすまし）を挙げている。
  • IPA は、更新は通常、Windows Update で自動的に行われるが、更新を管理している組織は、早期に展開するよう求めている。更新には、再起動が必要になることがある。
  • 11月18日号の週報も、この注意喚起を、「複数のマイクロソフト製品に脆弱性」として紹介している。

脆弱性以外の、週報の項目

  • 内閣官房の国家サイバー統括室（NCO）が、「個人情報の漏えい等につながる不正アクセスへの対策について」を公開した（週報11月11日号）。Web サイトやモバイルアプリの事業者に、デジタル資産の把握、脆弱性への対処、継続的な診断・監視、設計・開発段階からの対策、委託先を含むサプライチェーン全体での対策を呼びかけている。
  • JPCERT/CC が、「インシデント調査報告書チェックリスト」を公開した（週報11月18日号）。インシデントの調査を外部の組織に頼むときや、報告書を作る・確認するときに使うもので、頼む側と作る側が共通の認識を持つことを目的としている。

読むときの注意（筆者の整理）

  • 各項目の事実は、JPCERT/CC の週報と注意喚起、IPA の記述に限っています。各開発元の勧告そのもの（影響を受けるバージョンの一覧、CVSS の数値、回避策の細目）は、IPA が載せたものを除いて読んでいません（未確認）。
  • 週報は、JPCERT/CC が選んだ項目の一覧で、その月に出たすべての脆弱性ではありません。
  • 「悪用」の記述は、書いた主体（Microsoft、Rapid7、Binarly、Google、JPCERT/CC など）の発表のとおりです。このまとめで、悪用の規模や被害は推定していません。
  • 11月21日以降の公表は、このまとめには入っていません。10月分は、別のまとめ「今月の重要な脆弱性（2026年10月）」にあります。

用語メモ

CVE
脆弱性につける、共通の識別番号。
CVSS
脆弱性の深刻度を、0〜10の数値で表す指標。v4.0 では、9.0以上が Critical。
エクスプロイトコード
脆弱性を突くためのプログラム。公開されると、攻撃が増えやすい。
バックポート
新しい版で直した修正を、古い版の配布物に取り入れること。バージョンの番号は変わらない場合がある。
リクエストスマグリング
Web サーバーとその手前の機器で、リクエストの区切りの解釈がずれることを突く攻撃。
IoC
攻撃を受けた痕跡を示す情報（通信先の住所など）。
