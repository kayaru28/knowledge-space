「富岳」への不正アクセス：公開されていた稼働状況のページから運用系に侵入、利用者の鍵や氏名など最大4,597名分が漏れた可能性と、運用の停止

理化学研究所が2026年11月16日に公表した、スーパーコンピュータ「富岳」と「理究」への不正アクセスを、公式のお知らせから整理する。11月10日〜13日の侵入、11月14日の運用停止、漏れた可能性のある情報（最大4,597名分の認証情報と、利用者のファイルにあった SSH 秘密鍵など）、理研の対応と利用者への案内。

初回公開 2026-11-19 ／ 更新日 2026-11-19

ひとことで言うと

理化学研究所（理研）は、計算科学研究センターが運用するスーパーコンピュータ「富岳」の運用系システムに、外部の第三者が不正に侵入したと公表した。11月12日の不審な通信を検知し、11月13日に不正アクセスの事実を確認、11月14日午前4時30分に「富岳」の運用を停止した（再開の時期は書かれていない）。

漏えいした、または漏えいした可能性がある情報は、利用者の氏名・メールアドレス・ID（最大4,597名）と、利用者のホームディレクトリのファイルの一部。ファイルには、理研の外のスーパーコンピュータやサービスに接続するための認証情報（SSH 秘密鍵、アクセスキーなど）が含まれる。

経緯（理研の発表）

  • 11月10日〜13日：外部の第三者が、インターネット上に公開されていた「富岳」の稼働状況を表示するウェブページ（ダッシュボード）を足がかりに、運用系の内部ネットワークに侵入していた。具体的な方法は調査中。
  • 11月12日：運用システムの保守管理を委託している先と連携し、不審な通信を検知して調査を始めた。
  • 11月13日：16時33分に不正アクセスの事実を確認。20時59分に文部科学省へ報告。22時07分に、侵入に使われたシステムを隔離。
  • 11月14日：4時30分に「富岳」の運用を停止し、外部からのアクセスを遮断。20時20分に、管理用の鍵を入れ替えた。
  • 11月15日：10時51分に HPCI の関係機関へ報告。16時18分に、利用者にメールを送り、実行中・待機中の計算ジョブをすべて停止し、全利用者のログイン用の公開鍵を無効にした。
  • 11月16日：17時55分に個人情報保護委員会へ報告。同日、お知らせを公表。

漏れた、または漏れた可能性がある情報

  • 利用者の認証システムに登録された情報（最大4,597名）：「富岳」の利用者（最大4,222名）の氏名・メールアドレス・ID。「理究（りきゅう）」の利用者（最大375名）の氏名・メールアドレス。
  • 利用者のホームディレクトリに保存されていたファイル：理研の外のスーパーコンピュータやサービスに接続するための認証情報（SSH 秘密鍵、アクセスキーなど）と、利用者が保存していたファイル（研究データ）。
  • 研究成果が外部に流出したことを示す具体的な事実は、現時点では確認されていない。対象のファイルに第三者の個人情報が含まれているかも、確認中。

分かっている被害と、確認された改ざん

  • 侵入者は、内部の複数のサーバを不正に操作していた。
  • 侵入されたサーバの一部で、不正なプログラムの設置など、システムの改ざんがあった。
  • 侵入者は、取得した認証情報の一部を使って、ほかのシステムへの接続を試みていた。二次被害の有無は、関係機関と協力して調査中。

理研の対応と、利用者への案内

  • これまで：運用の停止、侵入経路の遮断、侵入に使われたシステムの隔離、管理用の鍵の入れ替え。全利用者のログイン用の公開鍵の無効化。
  • 今後：悪用されたソフトウェアの脆弱性への対処、侵入されたサーバの再構築、ネットワーク構成の見直し、AI を活用したセキュリティ対策などの再発防止策のうえで、運用を再開する。運用保守の役割分担も、早急に見直す。新しい事実は速やかに公表する。
  • 利用者への案内：「富岳」に保存していた SSH 秘密鍵や認証情報を、接続先で無効にし、必要なものを再発行する。「富岳」や理研をかたる不審なメールに注意する。理研がメールでパスワードなどを尋ねることはない。

読むときの注意

  • 読んだのは、理研の2026年11月16日付のお知らせだけ。以後の更新は未確認。
  • 侵入の具体的な方法、悪用された脆弱性、運用の再開の時期、二次被害の有無は、お知らせの時点で未公表。
  • 運用の停止中の影響（研究や産業利用への影響の大きさ）は、お知らせに書かれていない。

見方（筆者の整理）

  • 入口は、稼働状況を見せるための公開のページだった。計算機そのものを狙うのでなく、公開されている周辺のページから運用系の内部に届いた、と読める。ただし、詳しい経路は未公表なので、断定はできない。
  • 被害は、個人情報（氏名・メール）に加えて、ほかの計算機やサービスに入るための鍵が含まれる点が大きい。理研は、全利用者のログイン用の公開鍵の無効化と、接続先での無効化の案内を、同じ時刻（11月15日 16時18分）にしている。
  • 保守管理を外部に委託している、と書き、今後の対応に、役割分担の見直しを挙げている。委託と責任の分担が論点の一つだと、理研自身が書いている。
