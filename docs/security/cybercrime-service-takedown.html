日本を狙った詐欺の裏側：Microsoft が3つの犯罪サービスを解体した

2026年10月14日に Microsoft が発表した、YAM Store、CoGUI、Iron Man の解体について、公式の発表から、犯罪の「サービス経済」の構造、経緯、措置の規模、組織の対策を図で整理する。

初回公開 2026-10-19 ／ 更新日 2026-10-19

ひとことで言うと

2026年10月14日、Microsoft の Digital Crimes Unit（DCU）が、Health-ISAC と共同で、国境を越えるサイバー犯罪を支える3つのサービス（YAM Store、CoGUI、Iron Man）を解体したと発表しました。きっかけは、2025年末に日本の警察庁が、日本の人々を狙った悪質なメッセージのキャンペーンを Microsoft に通報したことです。

詐欺のメッセージは、被害者が目にする一部にすぎません。その裏には、アカウント、フィッシングキット、偽サイトのテンプレートを売る「サービス経済」があります。今回の措置は、メッセージの送り手ではなく、供給者を狙ったものです。

20,000以上

100,000以上

3つのサービス

Microsoft の発表2本（10月14日付）より
サービス役割特徴
YAM Store（Storm-3119）初期アクセスを売る店。侵害・不正取得した Microsoft 365／Azure for Education のテナントや、Microsoft・Google のアカウントを販売オンラインショップのように運営。非営利団体や教育機関などのドメインを乗っ取り、そこから Microsoft 365 のアカウントを不正に作成することもあった。アカウント、ライセンス、ストレージを、経過年数や組織の種類（.edu、.org など）で分類して販売
CoGUI（Storm-2990）フィッシングキット。企業、金融機関、政府機関などを装った既製のWebサイトやメッセージを提供日本と米国の被害者を主な対象にしていた。2026年半ばから、後継の Iron Man に置き換わりつつあった
Iron Man（Storm-2990）フィッシングキット。信頼される組織を装う数千の既製テンプレートを提供ブランド、業種、国ごとに調整したメール、SMS、Web コンテンツを素早く展開できる。2026年6月に販売が始まった

Iron Man のテンプレート数は、On the Issues が「2,300以上、150を超える国・地域の組織を装う」、Security ブログが「2,335以上、139以上の国と地域」と、2本で違う書き方をしています。ここでは、どちらも原文のとおりにしました。

経緯

協力した組織

  • 日本の警察庁（NPA）、JC3（日本サイバー犯罪対策センター）
  • Health-ISAC（医療分野への影響に関する知見）
  • Resecurity、Cloudflare、Oracle、Proofpoint、TRM Labs（情報提供と捜査支援）
  • 米国シークレットサービスや国際的な法執行機関とも、情報を共有した
  • 複数の組織の情報を組み合わせ、AIツールの支援も受けて、当初は無関係に見えたアカウント、Webサイト、インフラを結びつけた

実施した措置と規模

法的手続き

米国フロリダ州南部地区連邦地方裁判所の命令に基づき、3つのサービスの基盤になっていたドメインを差し押さえ、リダイレクトしました。

アカウントとインフラ

YAM Store に関連する20,000以上のアカウントを無効にしました。Microsoft のサービス上でホストされていたインフラを削除し、解体を継続的に進めています。

ドメインのブロック

なりすましや詐欺に使われていた100,000以上のドメインをブロックしました。

被害の規模（2026年1月以降）

  • 3つのサービスの合計で、10億通以上の悪意あるメッセージを可能にした。
  • 75,000以上の組織を標的にした。そのうち7億5,000万通以上が、Microsoft の顧客を狙ったもの。
  • 150以上の国・地域の、消費者、医療機関、金融機関、その他の企業に影響した。
  • 運営者に、数千万ドル規模の収益をもたらしたとされる。

手口

キットが提供するテンプレートは、銀行、小売、運輸、通信、宅配、警察、税務などの官公庁を装います。メッセージは、次のような内容で、クリック、個人情報の入力、支払いを促します。

装う内容

  • 偽の配送通知
  • 通行料や罰金の未払い通知
  • 税金の還付
  • アカウントの確認

見破られないための仕組み

  • 国別のジオフェンシング
  • 偽の CAPTCHA
  • IP のブロック／許可リスト
  • 研究者の検知を避ける設定

下流の攻撃

  • 緊急性を煽るメッセージ
  • 悪性リンク経由の認証情報の窃取
  • デバイスコードフィッシング（トークンの取得）
  • 盗んだ決済情報による不正購入や金融詐欺

Iron Man System の機能

  • 被害者の操作を、リアルタイムで監視・制御できる方式（WebSocket）
  • Telegram による即時の通知
  • パネルは主に中国のホスティング事業者に置かれている

YAM Store がアカウントを手に入れる5つの段階

  1. 偵察: Tor 経由で匿名のまま、クラウドを使う組織を特定する。
  2. テナントの掌握: アプリケーション専用の認証でディレクトリを操作し、パスワードのリセットやライセンスの割り当てを行う。
  3. ストレージの悪用: Global Administrator の侵害後、サービスプリンシパルを追加し、SharePoint／OneDrive をホスティングに使う。
  4. フィッシングと DNS の基盤: Cloudflare を通じて、フィッシングのドメイン、SSL 証明書、ルーティングを一元管理する。
  5. ストアフロントと収益化: 自動化した店舗で転売し、下位の再販売者も置く。

組織の対策

Microsoft の Security ブログが挙げている推奨策です。侵害の指標（IoC）の一覧は、本文には載っていません。

ユーザー教育

緊急性や公式を装う文面を疑い、送信者や企業に、別の経路で確認します。サインインのときは、対象のアプリを確認します。

メール保護

Exchange Online Protection と Defender for Office 365 の推奨設定を確認します。Safe Links を、内部の受信者にも適用します。

権限

最小権限とゼロトラストの原則を適用し、Global Administrator の権限を絞ります。

認証

パスキーと MFA を導入し、特権アカウントには、耐フィッシング性の高い MFA を条件付きアクセスで要求します。MFA やパスキーの登録は、信頼できる場所とデバイスからのみ許可します。

ネットワーク

ネットワーク保護を有効にし、悪性ドメインへのアクセスを防ぎます。

個人が自分を守るための具体的な手順は、On the Issues の発表には示されておらず、Microsoft Threat Intelligence の別のブログを参照するよう案内されています。上のユーザー教育の「疑う、別の経路で確認する」が、個人にも当てはまる基本です。

用語メモ

初期アクセスブローカー（IAB）
侵入のための入り口（アカウントや認証情報）を、攻撃者に売る業者。
フィッシング・アズ・ア・サービス
偽サイトやメッセージの作成キットを、サブスクリプションで貸し出す犯罪サービス。
テナント
Microsoft 365 などで、組織ごとに割り当てられる利用環境。
ジオフェンシング
地域を限って、表示や挙動を変える仕組み。
デバイスコードフィッシング
正規のログイン画面を使い、利用者にコードを入力させて、トークンを取得する手口。
ドメインの差し押さえ
裁判所の命令で、ドメインを管理下に置き、悪用を止めること。
