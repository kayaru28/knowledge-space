AIで一人ひとりに合わせたフィッシングメール：大学職員7,741人への実験で、クリック率は一律の文面の約2.7倍、費用は1通0.03ドル未満

USENIX Security 2026 の論文「A Large-Scale Study of Personalized Phishing using Large Language Models」から、メールアドレスだけを手がかりに公開情報を集めてAIで文面を作る流れ、4種類のメールの比較、公開情報の量との関係、費用、迷惑メールの判定、実験の条件と限界を整理する。

初回公開 2026-10-29 ／ 更新日 2026-10-29

ひとことで言うと

ドイツの大学の職員7,741人を対象にした実験で、メールアドレスだけを手がかりに、公開情報を集めてAIで一人ひとりに合わせた文面を作ると、リンクのクリック率は10.0%になりました。全員に同じ文面を送った場合（3.7〜4.1%）の約2.7倍です。AIの費用は、1通あたり0.03ドル未満でした。

専門家が手で一人ひとりに合わせた場合は24.2%と、さらに高い結果でした。ただし、100通で約11時間40分かかっています。2026年8月の国際会議 USENIX Security 2026 で発表された論文の内容です。

実験のやり方

  1. メールアドレスを集める：大学の公開されたページから職員のアドレスを集めました。
  2. 公開情報を集める：アドレスで検索し、上位5件のページを取得。51.8%にあたる4,010人は公開情報が見つかりました。
  3. プロフィールを作る：AIが、ページから本人に関する情報だけを抜き出し、短いプロフィールにまとめます。
  4. 差出人と文面を作る：プロフィールに合う差出人（学会の案内、研修、国際交流など5つの分野）を選び、一人ひとりに合わせた文面を作ります。

使ったのは、手元で動かすオープンなモデル（Llama、DeepSeek、Gemma、Mistral、Phi の系統）です。外部のAIサービスを使うと見つかりやすいため、という前提でした。小さなモデルの出力の形を整えるために、GPT-4o で作った架空のデータで追加の学習をしています。

  • AIで合わせた文面は、一律の文面の約2.74倍（論文の数字）。差は統計的に有意です。
  • 一律の文面では、AIで作っても手で作っても、クリック率はほぼ同じでした。差を作ったのは「AIかどうか」ではなく「一人ひとりに合わせたかどうか」です。
  • 手で合わせた文面はAI版の約2.4倍ですが、人が1通ずつ調べて書くので、多くの人には送れません。AI版は、その手間を省く代わりに、効果は下がる、という位置づけです。
  • 同じ大学の2024年の訓練（5.3%と7.0%）と比べ、一律の文面のクリック率は下がっています。論文は、定型の文面を職員が見分けやすくなっている可能性を述べています。

公開情報が多いと、だまされにくい

  • 公開情報が少ない層と中くらいの層のクリック率は12.7%と12.1%。
  • 公開情報が最も多い層は、有意に低い結果でした。
  • 論文の見立て：情報が多いと、AIが要約や言い換えをして、個人の細かい情報が文面に残りにくくなり、かえって説得力が下がります。

迷惑メール対策のすり抜け

  • 大学の迷惑メール対策の機器が不審と判定したのは、3,949通のうち1通だけでした。
  • ただし、実験では訓練用の送信サーバーを、判定の対象から外す許可リストに載せていました（配信の妨げを避けるため）。この数字は、対策が効かなかった証拠というより、「文面の内容だけでは見分けにくい」という論文の主張の根拠として載っています。
  • 論文は、この実験での送信者名のような、キャンペーンに共通する特徴があれば、判定できる余地はある、とも述べています。

論文が述べる限界

  • 手元の小さなモデルを使ったため、クリック率は下限に近い。外部の高性能なAIを小さく試したところ、プロフィールの質は上がった、と説明しています。
  • 対象は1つの大学です。訓練を受け、事前の説明もあった職員なので、他の環境では結果が違い、多くはより高くなる可能性がある、と論文は述べています。
  • 測ったのはリンクのクリックだけで、情報を入力したか、被害に至ったかは測っていません。
  • アンケートの回答は19件のみで、参考の値です。

論文が勧める対策

  • 被害を限定する技術：ネットワークの分割、最小権限、許可したアプリだけの実行、多要素認証、監視と対応。
  • 教育：一人ひとりに合わせた手口があること自体を、訓練に入れる。
  • 公開する情報の見直し：メールアドレスと結びつく個人の情報を、必要以上に出さない。

見方（筆者の整理）

  • 「クリック率が上がる」より注目したいのは、手間が数分の1になることです。人手では100通に半日かかった作業が、AIでは約4,000通に約2日（GPU 1枚）で済む、という論文の数字は、狙う側の費用の見積もりを変えます。
  • 公開情報が多い人ほどだまされにくい、という結果は、今回の仕組みでの観察です。「情報を出せば安全」という意味ではなく、論文もそう述べてはいません。
  • 多要素認証や権限の分離のような、「だまされたあとの被害を小さくする」対策が、論文の勧めの中心です。
