セキュリティ

Discord が、公開サーバーの会話を Web 検索に出せるようにする：11月16日にサーバーの Web ページ、12月中旬にメッセージ、止める設定は10月27日から

Discord が2026年10月27日に発表した、発見対象のサーバー（Discoverable Servers）の公開チャンネルの会話を、Web ページと Web 検索に出す変更について、日程、何が表示されるか、管理者と利用者が選べること、地域による既定の違いを、公式の発表から整理する。

初回公開 2026-10-31 ／ 更新日 2026-10-31

ひとことで言うと

Discord は2026年10月27日、発見対象のサーバー（メンバー1,000人以上の公開のサーバー）の公開チャンネルの会話を、Web ページと Web 検索に出せるようにすると発表しました。11月16日に、すべての発見対象のサーバーに Web ページができ、チャンネルの要約が出始めます。12月中旬から、公開チャンネルのメッセージが、ユーザー名とアバターなしで、Web 検索に出始めます。

管理者と利用者が表示を止める設定は、10月27日から使えます。何もしなければ、公開チャンネルはオンのままです（EU、英国、カナダ、ブラジル、オーストラリア、韓国では、メンバーのメッセージは初期状態でオフ）。

何がいつ変わるか

Discord の発表より（発見対象のサーバーだけ）
変わるものいつから内容選べる人
サーバーの Web ページ11月16日サーバーを説明するページ。発見対象のすべてのサーバーに作られる。管理者が作っていなければ、サーバーのプロフィールをもとに、既定のページが公開される。要らなければ、コミュニティのサーバーに戻せる管理者
チャンネルの要約11月16日以降の会話サーバーで話題になっている内容の、自動の要約を、Web ページに載せる。ユーザー名とアバターは出ない管理者（元にするチャンネルの変更、表示の調整、完全なオフ）
チャンネルのメッセージ12月中旬から（段階的）公開チャンネルで、メンバーが質問に答えた内容が、メンバー自身の言葉のまま、Web ページと検索に出る。ユーザー名とアバターは出ない。それ以前のメッセージは出ない管理者（対象のチャンネル）と、メンバー（自分のメッセージ）

対象と目的

  • 対象：発見対象のサーバー（Discoverable Servers）だけ。条件は、メンバーが1,000人以上、作ってから8週間以上、活動と安全の要件を満たすこと。現在は、63,000を超える。非公開のサーバー、ダイレクトメッセージ、グループのダイレクトメッセージは、対象外で、常に非公開。
  • 表示の対象：サーバーの全員に見える「公開チャンネル」。表示するチャンネルは、管理者が決める。表示される可能性があるチャンネルには、表示（ラベル）が付く。
  • 試行：Discord は、発見対象のゲームのコミュニティ（NBA 2K、Rust、Dead by Daylight など）で、メッセージの表示を試している。試行の間の投稿は、管理者とモデレーターのものだけだった。
  • 目的（Discord の説明）：多くの掲示板の会話が Discord に移り、役に立つ情報が、外から見つけられなくなっている。それを、Web 検索で見つかるようにしたい。

管理者が選べること

  • 今日から（10月27日）：サーバーの設定の「Web Presence」で、どのチャンネルを対象にするか、すべてオフにするかを選べる。
  • 何もしないと：公開チャンネルはオンのまま。11月16日に、Web ページが公開され（未公開の場合）、チャンネルの要約が始まる。12月中旬から、メッセージが始まる。
  • Web ページを自分で公開したい場合は、今日から公開できる。Web ページが要らない場合は、発見対象をやめて、コミュニティのサーバーに戻す。

利用者が選べること

  • 表示を止める：ユーザー設定の「データとプライバシー」で、チャンネルのメッセージを表示するかどうかを選べる。1つの設定が、参加しているすべての発見対象のサーバーに効く。今日から使え、12月中旬の前でも、あとでもよい。
  • 止めたあと：止めたあとに送ったメッセージは出ない。オンの間に送ったメッセージは、Discord で削除しない限り、残る。12月中旬より前のメッセージは、設定にかかわらず、出ない。
  • 要約は別：チャンネルの要約は、広い話題から別に作られ、管理者が止めない限り、Web ページに出る。ユーザー名とアバターは出ない。
  • 地域による既定の違い：EU、英国、カナダ、ブラジル、オーストラリア、韓国では、法的な制限から、メンバーのメッセージの設定は、初期状態でオフ（利用者がオンにしない限り、出ない）。ティーン年齢の層は完全に対象外で、成人になるまでオンにできない。それ以外の地域では、利用者がオフにしない限り、オン。日本は、この一覧に含まれていない。

読むときの注意

  • この記事は、Discord の公式ブログ（2026年10月27日）と、サポートの記事（日本語）にもとづく。表示は段階的で、最初のメッセージが Web に出るまで、数週間かかることがある。
  • メッセージに、ユーザー名とアバターは付かないとされているが、メッセージの本文に、名前や個人の情報が含まれる場合は、どう扱われるかを、この記事では確認していない。
  • Web の検索で、どの検索エンジンが、どのように表示するかは、確認していない。
  • プライバシーへの懸念を指摘する報道があるが、この記事では、公式の資料のみを扱った。

見方（筆者の整理）

  • 「何もしないと、オン」の設定が、管理者側と、日本を含む多くの地域の利用者側にある。見たくない場合は、11月16日（Web ページ）と12月中旬（メッセージ）の前に、設定を確かめる必要がある。
  • 公開チャンネルに書いたことが、Web 検索に出る、という変更。「サーバーの外の人に見える場所」の意味が、「サーバーに入れば見える」から、「検索で見える」に広がる。これまで、誰かが外部に転載しない限り見えなかった会話が、対象になる。
  • 12月中旬より前のメッセージは出ない、という線引きがあるため、これから書くメッセージが対象。書く場所のラベルを確かめる、が、利用者にできる最初の対応になる。

用語メモ

発見対象のサーバー（Discoverable Servers）
Discord のサーバー発見の機能に載っていて、招待のリンクがなくても誰でも参加できる、公開のサーバー。
サーバーの Web ページ（Server Web Page）
サーバーを紹介する、Web 上のページ。
チャンネルの要約
公開チャンネルの会話を、自動で要約した文。
コミュニティのサーバー
大きな集団向けの道具を備えたサーバー。参加には、招待のリンクが必要。
Web Presence
サーバーの設定の中の、Web での表示を決める項目。
