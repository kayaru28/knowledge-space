広告が表示されただけで感染する：Citizen Lab が初めて確かめた「AdFection」と、広告の仕組みの弱点

2026年10月15日、Citizen Lab は、ネット広告の入札で標的を選び、表示されただけでスパイウェアに感染させる攻撃を、実際の被害として初めて確かめたと発表した。広告1回の表示で起きること、アルジャジーラでの確認、4か月で約38億件の入札という規模、広告業界の対応、身を守る方法を、報告から図で整理する。

初回公開 2026-10-23 ／ 更新日 2026-10-23

ひとことで言うと

研究機関の Citizen Lab は2026年10月15日、ネット広告が表示されただけでスパイウェアに感染させる攻撃を、実際の被害として初めて技術的に確かめたと発表しました。この攻撃を AdFection と呼んでいます。

イスラエルの Discover-Tech という会社が、広告の会社を名乗りながら、傭兵型のスパイウェア（政府などに売られる監視用のマルウェア）の会社のために、広告の入札で標的を選んで感染させる仕組みを提供していました。国際報道機関のアルジャジーラでは、2024〜2025年に少なくとも45台が標的にされました。Google と広告の業界団体 IAB Europe は、この会社を「認定」の一覧から外しました。

広告1回の表示で何が起きるか

ネット広告の多くは、表示のたびに一瞬で行われる入札（リアルタイムビッディング）で決まります。入札の依頼には、端末の広告 ID や IP アドレスなどが含まれ、特定の1人に向けて広告を出せます。しかも広告は、画像だけでなく、プログラム（JavaScript）を動かせます。Discover-Tech は、この2つを組み合わせていました。

アルジャジーラで確かめられたこと

アルジャジーラが提供した通信の記録では、感染した端末が、まず Discover-Tech のサーバー（広告の表示）、次に Candiru のスパイウェアの確認用のサーバー（端末を調べる）、最後に指令のサーバーへと、同じ順に接続していました。感染した端末の1台から見つかった Windows 向けのファイルは、2021年に Citizen Lab が報告した Candiru のスパイウェアと同じ特徴を持っていました。Citizen Lab は、攻撃を特定の政府には結びつけていません。

どれだけの広告が出ていたか

Citizen Lab は、Discover-Tech のサーバーが公開していた入札の記録を、2026年3〜6月の4か月分調べました。

Discover-Tech の広告は、何百万台もの端末を Candiru のサーバーに接続させてもいました。Citizen Lab は、大規模な追跡と下調べのためとみています。

表示の記録は、各国の国防や外交の機関、NATO、国連、EU の機関、送電網の会社、半導体の会社、報道機関などのネットワークにも見られました。ただし、表示されたことは、標的にされたことや感染したことを意味しません。少なくとも情報は集められたとみられ、感染がなかったか調べる必要がある、と Citizen Lab は書いています。政府のネットワークで表示が見つかった国（24の国と地域）に、日本は含まれていませんが、調査は続いています。

広告業界の対応

Discover-Tech は、2020〜2026年、Google と IAB Europe が管理する「認定」「承認」の広告会社の一覧に載っていました。Citizen Lab は、正規の広告の活動の証拠は見つからなかったとしています。業界の審査は、会社の自己申告に頼っていた、という指摘です。

身を守るためにできること

個人（Citizen Lab の推奨）

  • 信頼できる広告ブロックの拡張機能を使う。
  • 追跡を防ぐブラウザを使う。
  • 端末の広告 ID を定期的にリセットし、広告の追跡を切る。
  • 家のルーターなどで広告をブロックする。

組織（Citizen Lab の推奨）

  • 組織の出入口と、支給した端末で、広告と追跡をブロックする。
  • 端末の管理の仕組み（MDM）で、支給した端末の広告 ID を切る。
  • 追跡の少ないブラウザへ移る。

狙われやすい立場の人

  • 立場や仕事のために狙われるおそれがある人は、専門家の助けを求める（Citizen Lab）。

見方

ゼロクリックの攻撃は、これまでメッセージのアプリなどの弱点を使うものが知られていました。今回は、ほぼすべてのアプリと Web サイトにつながる広告の入札が、標的の選別と感染の入口になりました。広告 ID で1人を狙えること、広告がプログラムを動かせること、広告会社の審査が自己申告に頼っていたことが重なっています。広告をブロックすることは、プライバシーだけでなく、セキュリティの対策でもあります。
