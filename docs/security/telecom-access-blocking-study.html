総務省が、サイバー攻撃への防御としてのアクセス遮断の検討を開始：11月20日に作業部会の初会合

サイバー攻撃による大規模な漏えいを受けて、総務省が始めた、通信事業者のアクセス遮断などの検討を、大臣の会見と第1回会合の資料をもとに、経過、法律上の整理、過去の議論、論点の案に分けて整理する。

初回公開 2026-11-28 ／ 更新日 2026-11-28

ひとことで言うと

総務省は、サイバー攻撃で大規模な個人情報の漏えいが起きたときに、通信事業者がアクセス遮断（ブロッキング）などで閲覧を抑えられるかを検討し始めました。大臣が11月10日に表明し、11月20日に作業部会の第1回会合を開きました。

結論はまだ出ていません。事務局は、来年早々のとりまとめを予定しています。

何を検討するか

  • 背景：同時に大量の個人情報が漏えいし、漏えいした情報を不特定多数の目にさらすとする脅迫の事案が起きている、と事務局の資料は書いています。
  • 課題：近時の攻撃の特徴と国民へのリスク、アクセス遮断を含む抑止策の法的な課題など。
  • 構成員：内田真人氏（早稲田大学）、宍戸常寿氏（東京大学）、曽我部真裕氏（京都大学）、橋爪隆氏（東京大学）、山本龍彦氏（慶應義塾大学。主査）。

法律上の整理

原則

通信の秘密は電気通信事業法で守られます。アクセス遮断は、すべての利用者のアクセス先を同意なく確認することが前提になるため、通信の秘密の侵害に当たる、と整理されています

例外として挙がるもの

当事者の同意、別の法律の根拠、通信事業者の業務上の必要（設備への攻撃元の検知など）、緊急避難

知る権利

遮断の一覧次第で、あらゆる情報への接続が止められるため、知る権利を制約するおそれがあります

技術の限界

遮断には回避の手段があり、有効性を高めるための技術的な課題もあります

これまでの遮断の議論

児童ポルノの遮断では、インターネットコンテンツセーフティ協会が基準に基づいて判定し、一覧を事業者に提供します。協会は、実施状況の公表と、異議の受付も行います。

事務局が議論してほしいとする点（案）

  1. 大規模な攻撃で漏えいなどの被害が広がるなか、緊急のアクセス抑止が求められるという考え方を、どう考えるか。
  2. 必要性と緊急性があり、抑止しなければ被害が広がるおそれが高い場合、緊急避難の考え方で、事業者が遮断を含む抑止策を取れる場面があるのではないか。望ましい手続きを官民で整理すべきではないか。
  3. 児童ポルノの遮断で機能している民間の自主的な枠組みの活用を含め、必要な手順を検討すべきではないか。
  4. 知見が蓄積されたら、緊急避難に当たる場面を類型にするなどして、将来の立法も排除されないのではないか。

事務局は、次の会合で関係する事業者・団体と有識者から意見を聞くことを提案しています。

書かれていないことと、読むときの注意

  • 第1回会合で出た意見と結論は、確認していません。
  • 対象にするサイトの基準、判定する主体、実施する事業者は、論点として挙がった段階です。
  • 議論してほしい点は事務局の案で、作業部会の結論ではありません。

用語メモ

アクセス遮断（ブロッキング）
通信事業者が、特定のサイトへの接続を検知して止めること。
通信の秘密
通信の内容や宛先を、勝手に知ったり、使ったり、漏らしたりしてはならないという決まり。
緊急避難
差し迫った危険を避けるためのやむを得ない行為を、条件を満たす場合に違法としない考え方（刑法37条）。
