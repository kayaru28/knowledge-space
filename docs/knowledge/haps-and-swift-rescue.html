空と宇宙のインフラをどう保つか：成層圏から届く携帯電話の電波と、落ちてくる宇宙望遠鏡 Swift を救う試み

ソフトバンクと Sceye が成層圏の HAPS で通話や緊急通報を確かめた試験と、大気の抵抗で高度が下がる NASA の Swift を民間の宇宙機で救う計画の経過を、公式の発表から図で整理する。

初回公開 2026-10-22 ／ 更新日 2026-10-22

ひとことで言うと

地上の基地局や、宇宙を回る観測衛星。私たちの頭上の通信や観測の仕組みを、どう広げ、どう保つかの試みが続いています。

ソフトバンクは米国の Sceye と組み、成層圏を飛ぶ「HAPS」に携帯電話の基地局を載せる試験をしました。空気より軽い機体が米国から約13日かけて太平洋を渡り、高知県の室戸岬沖の上空で、スマートフォンでの通話やデータ通信、118番への緊急通報、緊急速報メールを確かめました。一方、NASA の天文衛星 Swift は、太陽の活動で大気の抵抗が増え、予想より早く高度が下がっています。民間の宇宙機で軌道を押し上げる計画は、宇宙機自身の問題で断念されました。

1. 成層圏から届く携帯電話の電波

HAPS（High Altitude Platform Station）は、成層圏を飛ぶ機体に通信設備を載せ、地上に通信を届ける仕組みです。ソフトバンクと Sceye は9月2日、日本で初めての HAPS による試験サービスを行ったと発表しました。使ったのは、空気より軽く浮力で飛ぶ（LTA 型）Sceye の機体です。

ソフトバンクは、2027年以降に日本国内での商用化を目指すとしています。災害で地上の基地局が使えないときに通信を届けることや、ドローンなど空を飛ぶ乗り物向けの通信を想定しています。

2. 落ちてくる宇宙望遠鏡 Swift

Swift は、宇宙で最も強力な爆発であるガンマ線バーストなどを観測する NASA の天文衛星です。NASA の年ごとの予測で、太陽の活動が激しく大気の抵抗が増えたため、早ければ2026年夏に大気圏に再突入するおそれが出てきました。NASA は2025年9月、民間の Katalyst Space に3,000万ドルで、衛星をつかんで軌道を上げることを頼みました。

Katalyst の宇宙機 LINK は7月3日、航空機から空中で発射されるペガサス XL ロケットで打ち上げられました。しかし7月下旬に姿勢の制御に問題が起き、回転を毎秒約9度から4度未満に減らすなどの対応が続きました。NASA と Katalyst は8月19日、問題が続いているため、LINK が Swift をつかんで軌道を上げることはしないと発表しました。LINK は、将来の宇宙探査のための技術の実証として、Swift への接近と近くでの運用を試みるとしています。

Swift は、救出を待つ間、大気の抵抗を減らす向きで運用し、望遠鏡の観測をほぼ止めていました。救出の断念後、8月26日に紫外線・可視光望遠鏡と X 線望遠鏡を、9月にはガンマ線を捉えるバースト警報望遠鏡と、新しい爆発に自動で向きを変える運用を再開しました。

筆者の整理：どちらも、頭上のインフラを「代わりのもの」や「延命」でどう保つかの試みです。HAPS は地上の基地局が使えないときの代わりになりうる仕組みで、Swift の救出は、すでにある衛星を延命する仕組みです。軌道上で衛星をつかんで押し上げる作業は難しく、今回は宇宙機自身の問題で断念されました。また、太陽の活動による大気の抵抗の増加が、衛星の寿命を予想より縮めることがあります。
